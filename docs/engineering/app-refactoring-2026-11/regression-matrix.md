전후 전체 Jest가 통과했다. 아래의 “테스트 통과”는 명시적인 로컬 모형을 사용하는 자동 검증이며 실제 서버 통합 성공을 의미하지 않는다. 파일별 테스트 수·상태는 `validation.json`에 있다.

iOS 27.0.1 런타임은 이 호스트에 없어 미검증이다. 사용한 것은 iOS 27.0 / iPhone 17 시뮬레이터이며 SDK 26.5, Xcode 26.6 Release다. Android는 API 37 arm64 에뮬레이터다. 테스트 대상 앱을 사용자 실기기에 설치하지 않았다.

화면 자동화의 5회 반복은 두 플랫폼 모두 모든 명령이 완료됐으며 원시 시간·상태는 `measurements/*-journeys.json`에 있다. 캡처의 상태 표시줄 시간과 고양이·물결 애니메이션 위상은 전후 다르므로 전체 이미지의 바이트 동일성을 회귀 기준으로 쓰지 않았다. 상점·집중·홈 대표 캡처를 육안으로 대조했고, 변경 PNG 자체는 픽셀 전체를 비교했다.
