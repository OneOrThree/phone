# 시작과 자원의 수명

앱 부팅 순서와 계정 소유권 계약은 유지했다. 저장 상태·locale·세션 복구, 세션 검사와 홈 스냅샷 채택, 섬 유무에 따른 경로 판정, 계정별 서비스 활성화가 루트의 핵심 순서다. 세션 세대가 바뀌면 늦게 끝난 계정 채택을 버린다. 기존 요청 병렬화·Metro inlineRequires·음원 지연 로딩은 새 개선으로 집계하지 않는다.

| 자원                 | 소유자와 수명                               | 이번 처리                                                                                                                 |
| -------------------- | ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 표시용 시계          | `subscribeForegroundClock`, `useNow`, App   | 배경 예약 해제·복귀 벽시각 보정, 해제 중 콜백도 다음 예약 금지                                                            |
| 포그라운드 누적 연출 | `afterForegroundMs`                         | 동일한 두 구현 통합, active 중 흐른 시간만 누적                                                                           |

## 검증

새 `foregroundClock` 테스트는 배경 60초 콜백·예약 0, active 중복 통지 시 예약 중복 없음, 배경 마운트, 10회 진입/이탈 뒤 타이머·리스너 0, 콜백 내부 해제를 검증한다. 공용 `afterForegroundMs` 테스트도 일시 중지·복귀·취소·10회 반복 정리를 검증한다.

전후 전체 테스트에서 `App.bootConcurrency`, 세션 교체·화면 명령, `App.screenTimeDaily`, 저장·강제 업데이트·동작 줄이기·음원, `nativeLifecycle`, API 세션·오프라인·권한·자산 복구 테스트가 통과했다. `VerificationSession` 23개와 `VerificationCamera` 23개 테스트로 AI OFF·프리뷰·카메라 오류·배경 정책을 회귀 확인했다. 모형 기반 테스트 통과가 실제 기기 카메라·센서·푸시·앱 차단 검증을 대신하지 않는다.

네이티브 Release 시작·재실행 5회씩, 주요 화면 왕복과 같은 프로세스 12분 관찰은 `comparison.md`에 기록한다. 해당 관찰은 로컬 DEMO로 실제 로그인·원격 요청·촬영을 하지 않는다. CPU/시간은 관측 범위의 수치만 기록하며, 부팅 경로를 보존한 이번 변경에 초기화 속도 향상을 별도로 주장하지 않는다.
