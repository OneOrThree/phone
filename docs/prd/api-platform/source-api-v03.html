요청·응답 공통 규칙 서버 계약 제안

항목규칙
계약 상태모든 /v1 경로·JSON·이벤트는 예상 계약이다. 현재 앱은 로컬 목업이며 이 문서는 서버 구현 완료를 의미하지 않는다.
인증·권한auth 외 요청은 Authorization: Bearer <accessToken>. 서버는 본인/소속/시설 해금/역할을 검증한다. 방문자는 공개 요약만 받는다.
요청 위치경로 {islandId} 등은 Path 파라미터. GET 예시는 Query이며 본문을 보내지 않는다. 그 외 표기된 JSON은 Body. Content-Type: application/json.
성공 응답{data: ...} 형식. 데이터 없는 세션은 data=null, 빈 목록은 items=[]. 예시 숫자·ID·미디어 주소는 목업/설명용이다.
시간·단위시각은 UTC ISO 문자열, 날짜/시간대 집계는 YYYY-MM-DD + IANA timezone. activeSeconds는 초, targetMinutes·스크린타임은 분. 물고기/포인트는 정수.
페이지목록은 nextCursor=null이면 마지막. cursor는 불투명 값. 검색/탭/기간을 바꾸면 커서를 초기화한다. 메시지는 이전 묶음 방향이다.
멱등성 제안변경 요청은 Idempotency-Key: <UUID>. 같은 사용자·작업의 네트워크 재시도는 같은 키·같은 본문을 사용하고 동일 결과를 받는다. 보상·건설·구매는 DB 유일성도 별도 보장한다.
동시 변경expectedVersion은 해당 자원의 직전 GET 또는 변경 응답 version. 409이면 최신 상태를 받아 재확인한다. 명시하지 않은 자원에도 무조건 버전을 제출하는 것은 아니다.
원자 처리세션 종료/보상, 퀘스트 정산/포인트, 건설/차감, 상품 구매/차감/소유권은 각각 하나의 원자 작업. 화면 취소/닫기로 지출하지 않는다.
실패 UI입력 오류는 해당 필드, 권한/선행 조건은 사용 불가 사유, 통신 실패는 재시도. 이미 처리된 종료·구매는 같은 결과로 복구하며 중복 차감하지 않는다.
공통 오류400 형식, 401 인증, 403 권한/시설, 404 대상 없음, 409 상태/중복/버전/잔액, 422 입력 범위, 429 요청 제한, 5xx 일시 장애. 실제 에러 코드와 한도 수치는 서버 구현 때 고정한다.
