링크·MMP 를 business-api / data-api 에 붙이기

별도 레포 + Vercel + Neon 으로 가려던 링크 서버를 접고, 공개 표면은 business-api · 원장은 data-api 로 끌어온다. 광고 플랫폼이 주는 숫자는 다시 만들지 않고, Apple 이 주는 설치 신호는 우리도 직접 받는다. 글이 정본이고 이 그림은 요약이다.

  • 공개 경로nginx → business-api 만. /l/** /.well-known/** /console/**
  • 원장·트랜잭션data-api 는 /internal/* 만. 공인 노출 0
  • 콘솔business-api 안 Thymeleaf 3장. 알림 콘솔은 범위 밖
  • 광고비·클릭·CPIMeta·Google 대시보드. 우리는 만들지 않음
  • 설치·가입iOS 광고 = SKAN 복사본(집계) · Android = Install Referrer(기기)
  • PR #745링크 분리 코드 포함 머지. 걷어내기는 구현 PR

1무엇이 바뀌나 — 분리안 vs 붙임안

붙이면 위쪽 Vercel·Neon 덩어리와 거기로 향하던 화살표가 전부 사라진다. 그 화살표 하나하나가 A22 의 불변식(epoch·서명 자격·relay·이관 정지 창)을 만들던 원인이었다. 대신 바깥에서 들어오는 신호 두 개(Apple 포스트백, Play Referrer)가 그림에 들어온다.

붙이면 사라지는 호출새로 생기는 유일한 내부 계약그대로 · 바깥에서 오는 신호

2플랫폼이 주는 것 vs 우리가 세는 것

광고 플랫폼이 이미 세 주는 숫자는 다시 만들지 않는다. 우리가 세는 건 플랫폼이 못 주는 것(가입, 오가닉 퍼널)과 대조용 원본(Apple 포스트백 복사본)이다.

Meta·Google 대시보드우리 서버유저 단위
광고비·클릭·CPI준다안 만듦—
설치 (iOS 광고)준다 Apple 포스트백 수신자같은 포스트백 복사본 집계 · 늦게 도착안 됨 (Apple 정책)
설치 (Android 광고)준다 Google 은 Play 직접 집계Install Referrer 기기 단위됨
가입 (iOS 광고)전환값으로 뜸복사본의 전환값 집계 · 소수면 가려짐안 됨
가입 (Android 광고)못 줌claim 으로 유저 연결됨
오가닉 링크 퍼널못 줌클릭 · fingerprint/referrer · claim됨

SKAN 의 캠페인 번호(source-identifier)는 광고 네트워크가 정한다. 그래서 iOS 광고는 기본이 채널 단위이고, 네트워크가 캠페인 대응을 알려줄 때만 콘솔에서 캠페인에 매핑한다. iOS 광고에 fingerprint 를 쓰지 않는 이유: 광고 목적지를 랜딩으로 잡아야 해서 설치 최적화가 깨지고(CPI 악화), Apple 은 fingerprinting 을 동의 받아도 금지한다(ATT · 5.1.2).

3링크 타입 4개가 지나는 길

INVITE 는 로직 변경 0, 자리만 이동. CAMPAIGN 오가닉은 같은 파이프에 type·destination 이 얹히고, Android 는 랜딩이 Play URL 에 slug·click 을 심어 referrer 로 결정적으로 귀속된다. Android 광고는 referrer 를 누가 채웠느냐에 따라 아는 깊이가 다르다. iOS 광고는 Apple 이 서버로 직접 쏜다.

4데이터 — 테이블 5개, 이관 없음

기존 두 테이블은 rename(+ links 에 컬럼 추가). slug·id·클릭 이력 그대로. 신설 3개는 캠페인과 바깥에서 오는 신호 2종. 캠페인 귀속은 읽기 시점에 한다. 콘솔 상태(세션·잠금·폼 토큰)는 business-api Redis 라 DB 테이블 0.

5PR #745 — 링크 분리 코드를 안고 머지한다

열린 PR #745(알림 기반) 가 분리안 전제 코드를 싣고 있다. 결정: 빼지 않고 그대로 머지한다. 대신 구현 PR 이 사장 코드와 V52 링크 테이블 5개를 걷어내고, 그 전까지 아래 설정은 켜지 않는다.

6배포 순서

  1. #745 머지 — 링크 경로는 data-api 공개 컨트롤러가 계속 서빙
  2. data-api — 스키마 · invitelink 일반화 · /internal/* · #745 data-api 링크 사장 코드 + V52 링크 테이블 제거. 공개 컨트롤러는 남긴다
  3. business-api — 공개 표면 · referrer · SKAN 수신 · #745 business-api 링크 사장 코드 제거
  4. Infra — nginx 링크 경로 전환(reload 1회, 되돌리기도 1회 · 같은 DB 라 무손실), Cloudflare SKAN 경로 예외
  5. data-api — 링크 공개 컨트롤러 제거(전환 7일 뒤, 구 경로 호출 0)
  6. business-api — 콘솔
  7. 앱 — ① 파서·목적지 ② Install Referrer ③ SKAN 등록·전환값
