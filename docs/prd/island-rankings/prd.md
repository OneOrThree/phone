# 전망대 랭킹 요구사항

전망대에서 이번 주 주민 집중 순위와 섬 사이 평균 집중 순위를 본다. 순위 번호, 표시 시간, 본인 순위는 같은 집계표에서 나온다. 페이지를 넘기는 동안 집중 시간이 바뀌어도 그 표의 행이 빠지거나 중복되지 않아야 한다.

| 계약 | 결과 |
| --- | --- |
| GET `/islands/{islandId}/rankings/members` | 참가 상태·주민 순위·시간·본인 순위 |
| GET `/rankings/islands` | 참가한 섬의 순위·평균 집중 시간 |

KST 월요일00:00부터 다음 월요일00:00 미만이 한 주다. 원본 week는 ISO week-year이며 calendar-year로 대체하지 않는다. 최소2명은 원본 주민 랭킹 조건이다. 어떤 시점의 유효 주민을 셀지는 미결이며 1인 섬의 순위 제한이 섬 찾기 접근까지 막지는 않는다.

두 랭킹은 전망대와 현재 접근 권한을 검증한다. 루트 경로의 섬 간 랭킹도 검증한 사용자의 현재 섬 context를 한 번 정해 시설·참가 조건을 검사한다. 앱이 임의 currentIslandId를 헤더로 지정해 시설을 우회할 수 없다.

평균 분모·중도 가입·탈퇴/강퇴·동점·진행 ACTIVE 포함 여부·과거 마감은 제품 결정을 기다린다. 기존 리그의 행 존재 사용자 평균이나 UUID 순번을 새 규칙으로 확정하지 않는다. 수용 검증은 이 정책 표가 승인된 후 각 분기와 실제 snapshot 경합으로 수행한다. 랭킹 GET는 정산·보상 지급을 실행하지 않는다.
