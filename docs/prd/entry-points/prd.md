# 세션 시작 진입점 확장 (Entry Points) — PRD

> `docs/prd/apple-watch/policy.md` **D4**로 애플워치 PRD에서 분리된 자매 문서다. 헤드리스 세션 엔진(같은 문서 D2)이 공통 선행 조건이며, 착수 시점은 그 엔진과 워치 코어(페이즈 1) 이후다. 이 문서는 초안 골격이다 — 착수 전 자체 policy.md와 함께 살을 붙인다.

## 1. 배경

집중 세션의 시작은 현재 「앱 열기 → 카테고리 화면 → 과목 선택 → 시작」 한 경로뿐이다. 애플워치 PRD가 손목 진입점을 만들었듯, 폰 쪽에도 앱을 열지 않는 진입점 두 개를 추가한다. 두 기능 모두 워치와 무관한 폰 표면이라 별도 트랙으로 진행한다.

## 2. 범위

| # | 요구사항 (애플워치 PRD에서 이관) | 비고 |
|---|---|---|
| E1 (구 R14) | 홈스크린 위젯: 오늘 집중 시간 + 세션 시작 딥링크 | 기존 `com.oneorthree.gromo.widget` App ID 재사용 — 발급 0. **현행 `Widget.swift`는 정적 템플릿이라 「활성화」가 아니라 신규 구현**이다 — 오늘 누적의 App Group export부터 만들어야 함 |
| E2 (구 R15) | 「집중 시작」 App Intent: Siri·단축어·잠금화면 위젯에서 같은 인텐트로 세션 시작 | **앱을 열지 않는 시작이 목적이므로 인텐트는 네이티브에서 영속 명령 계층(애플워치 PRD §4.1)을 직접 호출**해야 한다 — 앱을 여는 구현은 목적 미달. 별도 entitlement 없음 — 발급 0 |

## 3. 이미 결정된 것 (정본: `docs/prd/apple-watch/policy.md`)

- **D10**: 인텐트 과목 미지정 시작의 기본값 = **최근 과목 자동** + 완료 후 변경 허용.
- **D2**: 공통 선행 조건 = 영속 세션 상태 머신 + 정산 저널 + 헤드리스 엔진 + 네이티브 명령 인박스.
- 계측 계약(애플워치 PRD §5): 이 진입점들의 시작은 `start_origin='widget' | 'intent'`로 구분한다.

## 4. 미결 (착수 시 이 문서의 policy.md로)

- 위젯 크기·표시 정보의 우선순위 (오늘 누적 vs 바로 시작 버튼)
- 인텐트의 세션 완료/취소 지원 범위 (시작만? 제어 전부?)
- 자동화(단축어 트리거) 발 세션의 계측·이상 패턴 감시 기준
