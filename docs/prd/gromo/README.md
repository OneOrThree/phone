# GROMO 1.x PRD

동결된 GROMO 1.x 제품과 서버 호환 유지에 필요한 기능 문서다. 앱 구현 기준은 `app/legacy/app-dev/`이며 Fishcat 2.0의 신규 기능을 이 폴더에 추가하지 않는다.

| 기능 | 문서 |
| --- | --- |
| Apple Watch | [`apple-watch/`](apple-watch/) |
| 챌린지 | [`challenge/`](challenge/) |
| 재화·시간조각 | [`currency/`](currency/) |
| 위젯·App Intent 진입점 | [`entry-points/`](entry-points/) |
| 그룹 | [`group/`](group/) |
| 1:1 문의 | [`inquiry/`](inquiry/) |
| 리그 | [`league/`](league/) |
| 모션 | [`motion/`](motion/) |
| 오브젝트 캐릭터 | [`object-character/`](object-character/) |
| 온보딩 | [`onboarding/`](onboarding/) |
| 스크린타임 | [`screentime/`](screentime/) |
| 주간 리포트 스터디 | [`weekly-review/`](weekly-review/) |

Fishcat이 기존 기능을 승계하거나 폐기하는 결정은 이 문서를 수정해 덮어쓰지 않고 [`../fishcat/`](../fishcat/)의 전환 문서에 기록한다.
