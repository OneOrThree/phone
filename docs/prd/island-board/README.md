기준 코드는 main `529a396e5f0f88cb78c172110920e1fa6b9388a9`다. 사용자 결정 → [기존 아키텍처 장부](../../architecture/decisions.md)·기존 도메인 정책 → 이 세트의 정책 → v0.3 예상 스펙 순서로 읽는다. 원본 /v1은 사용자 결정에 따라 신규 경로에서만 제거하며 legacy API는 보존한다.

원본은 GROMO-1739 화면별 API v0.3-proposed HTML이다. HTML SHA-256은 `2b56a4553d75863f1c1db50fd1c1f7123dd21ecf99bac4d38959ad945e9f9c30`, 이 추출 JSON SHA-256은 `82393732a4ff4b0fc1ba748783e3ce222784e9b34afc33f3019d0752d1797f8f`다. 원본의 샘플 ID/숫자/응답을 수정하지 않았다. 실제 UUID·추가 검증/변경은 LLD에서 구분한다. 새 공개 계약 개수는 6개이며 내부 어댑터는 추가 화면 계약으로 세지 않는다.

공통1750/구현1751~53, 이벤트1754/전송1755, 소속1758/관리1761, 집중1763·기록1768·경제 설계는 선행 의존이다. 이 기준 main에 없는 문서/코드의 상대 링크를 만들거나 배포된 것으로 간주하지 않는다. 현재 작업과 통합 완료 상태는 후속 구현 PR에서 대조한다. 미답 정책은 [출시 조건](policy.md#결정-대기와-출시-조건)에 남긴다.
