# 섬 건설 요구사항

주민이 회관에서 다음 시설을 고르고, 서버가 공동 잔액과 선행 시설을 확인한 뒤 한 번만 건설한다. 목표를 고르는 행위에는 돈이 들지 않는다. 실제 건설이 확정될 때 시설과 차감 내역이 함께 저장된다.

| 계약 | 사용자 결과 | 구현 |
| --- | --- | --- |
| GET `/islands/{islandId}/construction-options` | 현재 목표·공동 잔액·선택/건설 가능 사유를 본다 | 1767 |
| PUT `/islands/{islandId}/construction-target` | 건설할 목표만 바꾼다 | 1767 |
| POST `/islands/{islandId}/constructions` | 재검증한 가격으로 시설을 완공한다 | 1767 |

회관→게시판은 고정 단계다. 게시판 이후 전망대·우체통·방송기를 고를 수 있으며 전망대와 우체통이 모두 있어야 상점을 지을 수 있다. 방송기를 상점의 추가 선행 조건으로 만들지 않는다. 방송기 가격 100 village_points만 원본에서 확정했다. 다른 가격과 초기 필요 집중량은 운영 정책 확정 전 임의 숫자로 채우지 않는다.

완료 조건은 세 계약, 선행 그래프, 서버 가격 설정과 동의 버전, 목표 무차감, 건설·차감·사건의 단일 Data TX, 공동 재화와 개인 재화 분리, 실제 동시성 검증 계획이다. 완료한 시설은 중복 결제하지 않으며 같은 명령의 응답 유실은 저장한 결과로 복구한다. 외양 전체 상태와 버전도 완공 TX에서 갱신한다.

초기 건설은 집중 정산의 시간 배분·초과 기여 처리 결정(FR-D02)이 먼저 필요하다. 공동 건설/목표 변경의 실행 권한도 미결이다. 설계는 처리 경계를 정하지만 이 조건이 해결되지 않은 기능을 활성화하지 않는다. 철거·환불·사용자 파일 업로드·새 재화 종류는 이 세 계약의 범위가 아니다.
