QQ01~03·QQ05 잔여 및 집중/측정 정본이 해결되기 전 새 생산 데이터를 만드는 기능과 정산은 닫는다(QQ04·보상 amount 는 2026-09-18 확정, QQ01~03·보상 귀속은 2026-09-19 확정 — [결정 로그](../decision-log.md)). **2026-09-19 기준 남은 게이트**: ① 집중 측정 정본 — 집중 세션 시작 게이트 선행 작업(GROMO-1924 PR #815)은 main 에 들어왔고, 게이트를 실제로 여는 것은 운영 설정이다 ② QQ05 보상 설정 revision 등록 방식 ③ QQ03 복수 기기 병합(1806) ④ realtime 전달 배선(outbox 적재까지만 구현) ⑤ 스크린 퀘스트 — 1930(스크린타임 날짜 축 UTC 전환)까지 생성 자체가 422(Q01). 그래서 구현(GROMO-1773)은 생성·정산을 `island-quest.creation-enabled`·`island-quest.settlement-enabled`(기본 false, 게이트별 503)로 닫아 두었고 조회·수정은 열려 있다. 설계 완료가 이 제품 결정의 완료를 뜻하지 않는다. 유효한 기존 챌린지를 새 퀘스트로 자동 마이그레이션/중복 등록하지 않는다.
