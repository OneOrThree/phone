# Fishcat 결정 로그

> 제품·정책 결정의 **단일 장부**. 결정은 **여기에 먼저 적고** 해당 도메인 `policy.md` 로 전파한다 — 도메인 문서가 이 표와 어긋나면 이 표가 맞다. 뒤집힌 결정은 지우지 말고 취소선 + 후속 행으로 남긴다([아키텍처 결정 장부](../../architecture/decisions.md) 머리말 규약과 같다).
> ID 는 날짜 안에서 유일하다 — 도메인 문서에서 인용할 때는 「2026-09-18 재영님 결정 D1」 형식으로 날짜와 함께 적는다. 상태: **확정** · **보류** · **확인 중** · **설명 대기** · **폐기**.
> **경계**: 인프라·아키텍처 결정(인증·Kafka/Redis·서비스 경계)은 [`docs/architecture/decisions.md`](../../architecture/decisions.md)(A 번호), 제품·정책 결정(재화·권한·건물·시간축…)은 이 로그. 둘 다 걸치면 이 로그에 적고 A 번호를 가리킨다.
> 숫자만 있는 티켓 번호는 전부 Jira `GROMO-####` 이다. 기획 정본은 `OneOrThree/planning-document` 레포의 `policy-2026-09-14.md`(이하 「기획 정본」)이며 이 레포에는 없다.
