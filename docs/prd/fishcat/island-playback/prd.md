# 공용 음악 요구사항

방송기가 있는 섬에서 주민들이 같은 ASMR을 듣는다. 집중 화면의 소리 시트와 섬 방송기가 같은 서버 재생 상태를 사용한다. 한 주민이 곡을 바꾸거나 멈추면 다른 주민도 같은 변경을 받는다. 각 기기의 음량·음소거는 자기 기기에만 적용된다.

| 계약 | 결과 |
| --- | --- |
| GET `/islands/{islandId}/playback` | 현재 곡·재생 상태·기준 위치·서버 시각·버전 조회 |
| PATCH `/islands/{islandId}/playback` | 소유한 곡 선택 또는 재생/일시정지. 상태 버전 검사 후 전체 상태 반환 |

방송기 미건설이면 화면은 조회를 생략할 수 있지만 서버도 두 경로를403으로 막는다. 같은 섬의 활성 주민 누구나 조작하며 방장 승인이나 투표는 요구하지 않는다. 상점에서 소유한 ASMR만 선택할 수 있고 공용 조작은 비용을 다시 차감하지 않는다.

동시 조작은 먼저 확정한 명령만 반영하고 나머지는409와 현재 상태로 재확인을 받는다. 네트워크 응답 유실은 같은 키로 복구하며 과거 곡을 다시 실행하지 않는다. 서버 기준 위치 계산과 트랙 끝 반복은 상세 설계의 단일 식을 따른다. 곡 소유·방송기·현재 주민 확인과 실제 변경은 동일 Data TX에 있어야 한다.

재생 선택 전 기본값은 곡 없음·정지·위치0이다. 무료 곡 지급이나 임의 자동 선택을 추가하지 않는다. 새 seek API, 사용자 음원 업로드, 음량 동기화, 사용자 기기들이 샘플 단위로 완벽히 일치한다는 보장은 범위 밖이다.
