# 축음기 화면 명세

GROMO-1845에서 꽃나팔 방송기의 완공 후 화면과 구매 피드백을 확정한다. 지도 외형의 기능명은 꽃나팔 방송기이고, 화면 제목은 짧게 `축음기`로 표시한다.

## 완공 화면

- 일반 섬 지도에서 축음기를 누르면 별도 상세 페이지 없이 축음기 배경 위에 구매 전용 패널을 연다. 일반 섬에서는 재생·정지·곡 변경을 노출하지 않는다.
- 패널은 닫기 전까지 항상 펼친 상태이며 드래그 핸들, 핫스폿 점, `턴테이블` 문구를 표시하지 않는다.
- 왼쪽 레코드판은 일반 섬에서 장식으로만 표시한다. 재생·정지 버튼과 개인 음량 조절은 낚시 집중섬의 활성 집중 세션에서만 제공한다.
- 오른쪽 구매 목록은 세로 스크롤하며 보유곡과 판매곡을 함께 표시한다. 일반 섬의 보유곡은 상태만 표시하고 누를 수 없다.
- 낚시 집중섬에서는 주민 누구나 집중 전과 활성 집중 중에 음원을 구매하고 보유곡을 선택할 수 있다. 선택은 재생을 자동으로 켜지 않는다.
- 공용 곡 선택·재생 상태와 각 기기의 실제 재생을 구분한다. 기기는 집중 세션이 active이고 공용 재생·개인 소리가 켜져 있으며 음량이 0보다 클 때만 재생한다. 세션 없음·휴식·집중 종료·개인 음소거·음량 0에서는 플레이어를 일시정지한다. 축음기를 열거나 곡을 선택해도 이 조건은 유지하며, 개인 정지를 서버 공용 정지로 전송하지 않는다.
- 판매곡을 누르면 구매 확인창을 연다. 음원은 상점으로 이동하지 않고 축음기에서 바로 산다.
- 낚시 집중섬에서는 집중 전과 활성 집중 중 모두 판매곡과 구매 동선을 노출한다. 모닥불 휴식 화면에는 축음기와 음악 기능을 노출하지 않는다.

- 기본 세 곡 `waves`·`campfire`·`forest-wind`는 모든 섬에 무료 제공한다. 서버 공동 인벤토리에 포함하고, 목록에 무료로 표시하며 구매 확인 없이 선택할 수 있다. 곡 선택만으로 재생을 켜지는 않는다. 기존 판매 목록이나 섬별 구매 기록이 없어도 제공한다. (2026-10-17)

## 구매 상태

| 상태      | 제목                   | 보조 내용                              | 행동                                                      |
| --------- | ---------------------- | -------------------------------------- | --------------------------------------------------------- |
| 확인      | `{곡명}를 구매할까요?` | 같은 섬 주민 모두가 함께 듣는다는 안내 | `취소`, `{가격}마리로 구매`                               |
| 성공      | `구매했어요`           | 없음                                   | 일반 섬 `확인` · 낚시 집중섬 `나중에`, `이 곡으로 바꾸기` |
| 잔액 부족 | `물고기가 부족해요`    | 필요량·현재량·부족분을 표시하지 않음   | `확인`                                                    |

일반 섬의 구매 성공은 `확인`으로 닫고 재생 상태나 현재 곡을 바꾸지 않는다. 낚시 집중섬에서는 구매 성공 후 새 곡을 공용 곡으로 선택할 수 있다. 구매 실패는 인벤토리와 재생 상태를 바꾸지 않는다.

## 상태와 권한

- 공사 전과 공사 중에는 기존 건설 화면에서 진행 상태를 보여 주며 음원 목록을 열지 않는다. 별도 축음기 모달 이미지는 만들지 않는다.
- 완공된 섬의 활성 주민은 방장 여부와 관계없이 일반 섬에서 구매하고, 낚시 집중섬에서 구매·선택할 수 있다. 재생·정지는 활성 집중 세션의 낚시 집중섬에서만 조작한다.
- 다른 섬 방문자에게 축음기는 터치 대상으로 노출하지 않으며, 눌러도 화면·안내를 열지 않는다.
- 판매곡이 없으면 보유곡만 표시한다. 낚시 집중섬에서 보유곡도 없으면 목록의 빈 상태를 표시한다.
- Android 뒤로가기를 누르면 구매 안내창만 닫고 축음기 화면은 유지한다.

## 에셋과 시안

- 지도와 모달은 기존 투명 PNG `src/assets/buildings/gramophone/day.png`를 공유한다. 원본 그림 영역은 632×910이며 앱에서 비율을 유지해 축소한다.
- 배경은 축음기 전용 일러스트 `src/assets/interiors/gram-cute-v1.png`(`art['interior/gram']`)를 세로·가로 공통으로 사용한다. 섬 지도 크롭 `bldbg/gram`은 쓰지 않는다. 집중 세션 중에는 기존 낚시 장면을 유지한다.
