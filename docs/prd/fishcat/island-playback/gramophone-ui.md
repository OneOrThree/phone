# 축음기 화면 명세

GROMO-1845에서 꽃나팔 방송기의 완공 후 화면과 구매 피드백을 확정한다. 지도 외형의 기능명은 꽃나팔 방송기이고, 화면 제목은 짧게 `축음기`로 표시한다.

## 완공 화면

- 지도에서 축음기를 누르면 별도 상세 페이지 없이 축음기 배경 위에 고정 패널을 연다.
- 패널은 닫기 전까지 항상 펼친 상태이며 드래그 핸들, 핫스폿 점, `턴테이블` 문구를 표시하지 않는다.
- 왼쪽에는 레코드판과 아이콘 버튼 두 개를 둔다. 삼각형은 재생, 사각형은 정지다.
- 오른쪽에는 현재 곡과 곡 목록을 둔다. 목록은 세로 스크롤하며 보유곡과 판매곡을 함께 표시한다.
- 보유곡을 누르면 같은 섬의 공용 곡을 즉시 선택하고 재생한다. 주민 누구나 조작할 수 있다.
- 판매곡을 누르면 구매 확인창을 연다. 음원은 상점으로 이동하지 않고 축음기에서 바로 산다.

## 구매 상태

| 상태 | 제목 | 보조 내용 | 행동 |
| --- | --- | --- | --- |
| 확인 | `{곡명}를 구매할까요?` | 같은 섬 주민 모두가 함께 듣는다는 안내 | `취소`, `{가격}마리로 구매` |
| 성공 | `구매했어요` | 없음 | `지금 재생하기` |
| 잔액 부족 | `물고기가 부족해요` | 필요량·현재량·부족분을 표시하지 않음 | `확인` |

구매 성공 후 `지금 재생하기`를 누르면 새 곡을 공용 곡으로 선택해 바로 재생한다. 구매 실패는 인벤토리와 재생 상태를 바꾸지 않는다.

## 상태와 권한

- 공사 전과 공사 중에는 기존 건설 화면에서 진행 상태를 보여 주며 음원 목록을 열지 않는다. 별도 축음기 모달 이미지는 만들지 않는다.
- 완공된 섬의 활성 주민은 방장 여부와 관계없이 구매·선택·재생·정지할 수 있다.
- 다른 섬 방문자는 배경과 외형만 볼 수 있고 구매나 공용 재생 상태를 바꿀 수 없다.
- 판매곡이 없으면 보유곡만 표시한다. 보유곡도 없으면 재생 버튼을 비활성화하고 곡 목록의 빈 상태를 표시한다.
