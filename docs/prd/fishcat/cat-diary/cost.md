# 고양이 일기 비용

> 상태: P0 추정(2026-11-12). 토큰 수는 가정이다. GROMO-2862 모델 비교에서 응답의 `usage` 로 실측해 이 문서를 고친다.

## 1. 가격 (1M 토큰당 USD, 표준가)

3사 모두 Batch 는 입력·출력 50% 할인이다.

| 급 | Claude | OpenAI | Gemini |
| --- | --- | --- | --- |
| 대형 | Opus 5.5 $4 / $20 | — | Gemini 4 Argon $2 / $10 → **2026-12-01부터 $4 / $20** |
| 중형 | Sonnet 5.5 $2 / $10 | gpt-6.1-sol $2 / $10 | — |
| 중소형 | — | gpt-6.1-terra $1 / $5 | Gemini 3.8 Flash $0.75 / $3.75 → **2027-01-01부터 $1.50 / $7.50** |
| 소형 | Haiku 5.5 $0.10 / $0.50 | gpt-6-luna $0.10 / $0.50 | Gemini 3.1 Flash-Lite $0.25 / $1.50 |

- 「codex」 모델(gpt-5.3-codex, $1.75 / $14)은 코딩 전용이고 Batch 가격이 없다. 비교에서 뺀다.
- Gemini 4 는 12월부터 Opus 5.5 와 같은 값이 된다. 비교에서 뺀다.
- Gemini 무료 등급은 입력을 제품 개선에 쓴다. 유료 등급만 쓴다.
- 출처(2026-11-12 조회):
  - Claude: https://platform.claude.com/docs/en/about-claude/pricing
  - OpenAI: https://developers.openai.com/api/docs/pricing

## 2. 일기 1편

가정:
- 입력 2,500토큰 = 고정 지시문·예시 약 1,800 + facts 약 700
- 출력 1,200토큰 = 본문 약 600 + 생각 약 600
- Batch 50%, 환율 ₩1,400/$ (11월 실제 1,340~1,364원보다 보수적으로 잡음)
- 프롬프트 캐시 할인은 넣지 않았다. 고정 지시문은 캐시되므로 실제는 더 싸다.

`1편 = (2,500 × 입력 단가 + 1,200 × 출력 단가) ÷ 1,000,000 × 0.5`

| 모델 | 1편 | 구독자 1명/월 (4.33편) |
| --- | --- | --- |
| Claude Opus 5.5 | $0.0170 · ₩23.8 | ₩103 |
| Claude Sonnet 5.5 · gpt-6.1-sol | $0.0085 · ₩11.9 | ₩52 |
| gpt-6.1-terra | $0.0043 · ₩6.0 | ₩26 |
| Gemini 3.8 Flash | $0.0032 · ₩4.5 (1월부터 ₩8.9) | ₩19 (₩39) |
| Gemini 3.1 Flash-Lite | $0.0012 · ₩1.7 | ₩7 |
| Claude Haiku 5.5 · gpt-6-luna | $0.0004 · ₩0.6 | ₩2.6 |

재작성(동기 호출, Batch 할인 없음)은 그 편 비용의 약 2배를 더한다. 출시 관문(재작성률 5% 미만)이면 월 비용에 5% 안쪽으로 더해진다.

## 3. 월 편수 시나리오

| 시나리오 | 구독자 일기 | 체험 일기 | 월 합계 |

가정:
- 신규 사용자 월 약 2,100명: 10-21~11-10 첫 사용 1,463명(21일)에서 계산
- 지금 MAU 약 1,500명 × 구독 전환 2% = 30명. 2% 는 RevenueCat State of Subscription Apps 2026 의 프리미엄(freemium) 앱 Day-35 전환 중앙값 2.1% 에서 가져왔다
- 체험권 2편
  - A1(자동): 신규의 60% 가 첫 주 1편, 5% 가 둘째 주 1편을 쓴다

- 활동 없는 주의 고정 문구는 0원이라 편수에 넣지 않았다
- B: MAU 1만, 신규 월 5,000명, 구독 200명

## 4. 수익

- 월 ₩2,900 을 가정했다. 부가세 10% 와 스토어 수수료 15%(Apple 소규모 사업자 프로그램, Google Play 구독)를 빼면 1명당 순매출은 ₩2,242 다.
- A(30명): 월 약 ₩67,000. 전환율이 1%·2%·5% 면 ₩34,000·₩67,000·₩168,000.
- B(200명): 월 약 ₩448,000.
- RevenueCat 2026 기준 체험 기간 17~32일은 42.5%, 4일 미만은 25.5% 가 결제로 넘어간다(중앙값). 체험권 2편(2주)은 그 사이다.

## 5. 결론

1. 구독자 쪽 API 비용은 순매출의 0.1~4.6% 다(1명당 월 ₩3~₩103 ÷ ₩2,242). 어느 모델이든 남는다.
2. 월 비용을 정하는 것은 **체험권 정책**이다. 자동 지급(A1)이면 중형 모델도 1만 원을 넘는다. **신청형(A2)이면 중형 모델이 ₩7,140 으로 들어온다.** 대형(Opus 5.5)은 A2 에서도 ₩14,280 으로 넘는다.
3. 모델은 [eval.md](eval.md) §3 출시 관문을 넘는 것 중 A2 기준 월 ₩10,000 이하인 가장 싼 것으로 고른다(GROMO-2862).
4. 성장 단계(B)에서는 상한을 「구독 순매출의 10%」로 바꾼다. B 의 10% 는 약 ₩44,800 이라 중형 모델도 들어간다.

## 6. 다시 잴 것

- 회사별 한국어 토큰 수. 같은 글도 토크나이저마다 토큰 수가 다르다.
- 생각 토큰. 가장 낮은 단계에서도 모델마다 다르다.
- 캐시 적중률. Claude 는 고정 지시문(약 1,800토큰)이 캐시되면 그 몫이 0.05배다. Batch 안의 캐시는 최선 노력이라 실측으로만 안다.
- 체험권 신청률과 1인당 사용 편수. 출시 첫 2주(GROMO-2871) 수치로 A2 가정을 고친다.
