# 신고센터 — 공식 근거와 긴급 대응 초안

[정책](policy.md) · [구현 범위](follow-up-scope.md) · [결정 로그](../decision-log.md)

조사일: 2026-09-22. **공식 자료의 내용, 서비스 적용 판단, 운영 제안을 구분한다.** 아래 조사와 절차 작성은 완료했으며 멘토링 일정 때문에 멈추지 않는다. 회사의 사업자 지위·출시 국가·실제 운영 연락처처럼 자료만으로 알 수 없는 사실은 마지막 표에서 별도로 관리한다. 법률 자문을 받은 문서라는 뜻은 아니다.

## 2. 즉시 사용할 수 있게 구체화한 운영 절차 — 제안

RP-긴급조치의 확정 흐름을 실행 절차로 구체화했다. 아래 세부안은 사용자 개별 확정과 구분한다.

1. **접수·분류:** ‘아동 안전/성착취’와 ‘구체적 위해 협박’을 긴급 분류로 접수한다. 일반 신고의 주 2회 일괄 검토를 기다리지 않고 담당·대체 담당에게 사건 번호와 내부 검토 링크를 보낸다. 알림에 원문이나 피해자 식별 정보를 넣지 않는다.
2. **초기 보호:** 운영자가 긴급성을 확인하면 해당 콘텐츠의 조회·전달·미리보기를 막고 계정을 임시 정지한다. 명백히 확인된 유해 정보의 확산 방지를 최종 조사 완료까지 미루지 않는다. 신고 이유 선택만으로 사용자 계정을 자동 정지하지 않는다.
3. **기록·증거:** 이미 서버에 있는 신고 대상 텍스트, 콘텐츠 식별자·작성 시각, 신고·조치 시각과 담당자를 제한된 사건 저장소에 기록한다. 외부 링크의 불법 이미지·영상을 자동 수집하거나 운영자 개인 기기에 내려받지 않는다. 이미지 첨부를 새로 요구하지 않는다. 실제 불법 자료를 취급해야 하는 사건은 수사기관의 적법한 지시·보존 근거에 따라 다룬다.
4. **수사기관 연락:** 즉각적인 신체 위험은 112로 신고한다. 확인된 아동 성착취 범죄는 운영 담당이 제3자 신고 경로로 관할 경찰에 접수하고 접수번호·기관·담당·요청사항을 기록한다. ECRM 본인 신고를 우회하지 않는다. 해외 관할 의무가 추가로 적용되는 경우 해당 기관 절차를 연결한다.
5. **자료 제공:** 기관 요청의 발신자·권한·범위를 검증한 뒤 필요한 자료만 지정된 안전한 경로로 제공한다. 외부 신고는 실제 승인된 담당자가 수행한다. 이 문서 작성 과정에서 외부 신고나 자료 전송을 실행하지 않는다.
6. **보존 예외 관리:** 진행 중 조사·분쟁·적법한 보존 요청은 일반 30일 파기와 분리한다. 보존 사유·근거·범위·담당·다음 검토일을 필수로 기록해 단순 ‘긴급’ 표시만으로 무기한 보관하지 않는다. 근거가 끝나면 불필요한 자료를 파기한다.
7. **최종 조치:** 중대 위반 확정 시 영구 정지하고 신고자에게 정형 결과를 통지한다. 임시 정지 사유가 해소되면 제한을 취소하고 오판에 따른 누적 제재도 정정한다. 콘텐츠 복구 여부는 별도로 판단한다.
8. **추적:** 일반 검토일에도 모든 미종결 긴급 사건과 임시 정지를 다시 살핀다. 담당자가 자리를 비우면 대체 담당에게 넘기며 알림 전달 성공만으로 사건 처리 완료로 보지 않는다.

특정 멘토의 답변만을 유일한 진행 조건으로 삼지 않는다. 조문으로 확인되는 조치와 제품의 유통 방지 수단은 계속 만들고, 회사별 적용 판단과 실제 담당 지정만 해당 출시 점검 항목으로 남긴다.
