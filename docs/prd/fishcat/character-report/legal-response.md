# 신고센터 — 공식 근거와 긴급 대응 초안

[정책](policy.md) · [구현 범위](follow-up-scope.md) · [결정 로그](../decision-log.md)

조사일: 2026-09-22. **공식 자료의 내용, 서비스 적용 판단, 운영 제안을 구분한다.** 아래 조사와 절차 작성은 완료했으며 멘토링 일정 때문에 멈추지 않는다. 회사의 사업자 지위·출시 국가·실제 운영 연락처처럼 자료만으로 알 수 없는 사실은 마지막 표에서 별도로 관리한다. 법률 자문을 받은 문서라는 뜻은 아니다.

**용어와 2.0 범위:** [Google의 정의](https://support.google.com/googleplay/android-developer/answer/14747720?hl=en)에 따르면 CSAE는 아동 성착취·학대의 행위와 콘텐츠를 포함하고, CSAM은 미성년자의 성적 행위를 담은 시각 자료를 가리킨다. **Catus 2.0에는 사용자 이미지·파일 업로드, 서버 저장, 다른 사용자에게 보여주는 기능이 없다.** 현재 처리 대상은 공지·댓글·채팅·편지 등 서비스 안의 **CSAE 의심 텍스트**와 그 텍스트가 외부 자료를 가리킨다는 신고다. 외부 자료가 CSAM으로 의심되면 해당 텍스트/링크와 사건 식별정보만 다루며 이미지·영상을 자동 수집하거나 운영 메일에 복제하지 않는다. 서비스에 없는 파일의 삭제·이미지 자동 탐지·이미지 증거 저장을 2.0 구현 범위로 잡지 않는다.

**14세 이상 설정의 의미:** 14~18세도 이용할 수 있으므로 아동·청소년 성착취 금지와 신고 절차를 제거할 근거가 되지 않는다. [Google Play 대상 연령 안내](https://support.google.com/googleplay/android-developer/answer/9867159?hl=en)는 13~15세·16~17세가 지역에 따라 아동에 해당할 수 있다고 설명하고, [국내 청소년성보호법 제2조](https://www.law.go.kr/법령/아동ㆍ청소년의성보호에관한법률/제2조)는 원칙적으로 19세 미만을 아동·청소년으로 정의한다. 다만 아래 공식 정책만으로 **24시간 상시 모니터링·즉시 확인 의무**를 도출하지 않는다. 운영 가능 시간, 긴급 제보의 실제 확인 경로와 앱의 출시 국가별 긴급번호 안내는 출시 전 정한다.

## 2. 즉시 사용할 수 있게 구체화한 운영 절차 — 제안

RP-긴급조치의 확정 흐름을 실행 절차로 구체화했다. 아래 세부안은 사용자 개별 확정과 구분한다.

2026-09-24 RP-메일정본에 따라 텍스트 신고 기록의 보관 장소는 자체 신고 DB가 아닌 접근 제한된 운영 메일함이다. 아래의 “사건 저장소”는 이 메일함과 승인된 운영 기록을 뜻하며, 실제 CSAM 의심 이미지·영상을 메일에 첨부하거나 링크에서 자동 수집하지 않는다. 메일 제공자의 접근·보존·삭제 범위는 출시 전 확인한다. 아래 보호·제재 조치는 **서비스가 관리하는 텍스트, 링크 노출, 계정**에 적용한다. 외부 사이트의 파일을 우리 서비스가 직접 삭제할 수 있다는 뜻이 아니다.

1. **접수·분류:** ‘아동 안전/성착취’와 ‘구체적 위해 협박’을 긴급 분류로 접수한다. CSAE 의심 텍스트와 CSAM 의심 자료를 같은 말로 기록하지 않는다. 일반 신고의 주 2회 일괄 검토를 기다리지 않고 지정된 운영 시간·전달 체계에 따라 담당·대체 담당에게 사건 번호와 내부 검토 링크를 보낸다. 알림 발송을 운영자의 확인으로 표현하거나, 운영 시간을 정하기 전에 야간·휴일 상시 대응을 약속하지 않는다. 알림에 원문이나 피해자 식별 정보를 넣지 않는다.
2. **초기 보호:** 운영자가 긴급성을 확인하면 서비스 안의 해당 텍스트·링크의 조회·전달·미리보기를 막고 계정을 즉시 임시 정지한다. 서비스 밖 파일의 삭제를 우리 조치로 기록하지 않는다. 명백히 확인된 유해 정보의 확산 방지를 최종 조사 완료까지 미루지 않는다. 신고 이유 선택만으로 사용자 계정을 자동 정지하지 않는다.
3. **기록·증거:** 서버가 확인한 신고 대상 텍스트, 콘텐츠 식별자·작성 시각과 신고 시각을 접근 제한된 운영 메일함에 접수한다. 운영자는 조치 시각·담당자·결과를 같은 사건에 연결해 관리한다. 외부 링크의 불법 이미지·영상을 자동 수집하거나 메일에 첨부하거나 운영자 개인 기기에 내려받지 않는다. 이미지 첨부를 새로 요구하지 않는다. 실제 불법 자료를 취급해야 하는 사건은 수사기관의 적법한 지시·보존 근거에 따라 다룬다.
4. **수사기관 연락:** 즉각적인 신체 위험에는 해당 국가의 검증된 긴급번호로 신고하도록 안내한다(국내 112). 구체적인 아동 성착취 정황이 있으면 운영 담당이 내부 최종 제재 확정까지 기다리지 않고 국내 사건은 182 또는 관할 경찰을 통해 제3자 신고·상담 경로를 확인한다. 실제 접수 시 접수번호·기관·담당·요청사항을 기록한다. 이는 모든 의심 신고의 법적 신고 의무를 단정하는 문장이 아니다. ECRM 본인 신고를 우회하지 않는다. 해외 관할 의무가 추가로 적용되는 경우 해당 기관 절차를 연결한다.
5. **자료 제공:** 기관 요청의 발신자·권한·범위를 검증한 뒤 필요한 자료만 지정된 안전한 경로로 제공한다. 외부 신고는 실제 승인된 담당자가 수행한다. 이 문서 작성 과정에서 외부 신고나 자료 전송을 실행하지 않는다.
6. **보존 예외 관리:** 진행 중 조사·분쟁·적법한 보존 요청은 일반 30일 파기와 분리한다. 보존 사유·근거·범위·담당·다음 검토일을 필수로 기록해 단순 ‘긴급’ 표시만으로 무기한 보관하지 않는다. 근거가 끝나면 불필요한 자료를 파기한다.
7. **최종 조치:** 중대 위반 확정 시 영구 정지하고, 확인된 답장 이메일이 있는 신고자에게만 정형 결과를 보낸다. 임시 정지 사유가 해소되면 제한을 취소하고 오판에 따른 누적 제재도 정정한다. 콘텐츠 복구 여부는 별도로 판단한다.
8. **추적:** 일반 검토일에도 모든 미종결 긴급 사건과 임시 정지를 다시 살핀다. 담당자가 자리를 비우면 대체 담당에게 넘기며 알림 전달 성공만으로 사건 처리 완료로 보지 않는다.

특정 멘토의 답변만을 유일한 진행 조건으로 삼지 않는다. 조문으로 확인되는 조치와 제품의 유통 방지 수단은 계속 만들고, 회사별 적용 판단과 실제 담당 지정만 해당 출시 점검 항목으로 남긴다.
