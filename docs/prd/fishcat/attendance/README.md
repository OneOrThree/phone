# 출석 보상

2026-11-12 설계. 에픽 GROMO-2855. **설계 문서이며 구현·배포 전이다.**

| 문서 | 내용 |
| --- | --- |
| [PRD](prd.md) | 문제, 목표와 지표, 사용자 장면, 기능 요구사항, 범위 밖 |
| [정책](policy.md) | 출석 판정·날짜 축·칸·보상 귀속·편집·승인 규칙의 정본과 결정 대기 |

읽는 순서: [결정 로그](../decision-log.md)의 2026-11-12 `AT-*` 행 → 정책 → PRD. 문서끼리 어긋나면 정책을 먼저 고치고 나머지를 맞춘다. 정책과 결정 로그가 어긋나면 결정 로그가 맞다.

## 한 줄 요약

사용자는 하루 한 번 출석판에서 「출석하기」를 눌러 그 주의 다음 칸 보상을 받는다. 한 주는 7칸이다. 보상은 현재 섬 통장으로 가는 물고기이거나 개인 보유품이 되는 꾸미기다. 운영자는 백오피스에서 이번 주·다음 주·기본 표의 7칸을 고치고, 다른 운영자의 승인을 받아 발행한다. 참여 현황도 백오피스에서 본다.
