# 기능별 App Store 이미지 카피 리뷰

리뷰일: 2026-08-10  
대상: `features-v1/` 9장  
추가 결과: `features-v1-copy-v2/` 9장

## 기존 세트 리뷰

### 잘 된 점

- 실제 앱 UI가 화면의 주인공이라 기능을 과장하지 않고 신뢰를 준다.
- `그룹 → 챌린지 → 누끼`가 색으로 구분되면서도 한 제품처럼 일관된다.
- 두 줄 헤드라인과 정면 단일 화면 구조가 App Store 축소 상태에서도 빠르게 읽힌다.
- 그룹방, 챌린지 설정, 코인 내기처럼 제품 차별점이 강한 화면을 골랐다.

### 보완할 점

- 기존 헤드라인은 기능 설명형 비중이 높아 사용자가 얻는 감정적 보상이 약하다.
- `만들어요`, `챌린지로`, `준비 끝`처럼 기능명을 직접 설명하는 어미가 반복된다.
- 누끼 세트는 기능 작동 방식은 명확하지만 `나만의 것`을 만든다는 즐거움을 더 강조할 수 있다.

## 카피 v2 방향

앱 화면, 배치, 배경색, 폰 크기와 그림자는 유지했다. 문구만 아래 세 축으로 바꿨다.

- 그룹: 기능보다 `함께라서 꾸준해지는 감정` 강조
- 챌린지: 설정 설명보다 `경쟁·약속·완주` 강조
- 누끼: 처리 기술보다 `유일성·간편함·완성의 재미` 강조

| 기능 | 화면 | 카피 v2 헤드라인 | 보조 문구 |
| --- | --- | --- | --- |
| 그룹 | 목록 | 혼자보다, 함께라서 꾸준해요 | 같은 목표의 사람들과 집중 습관을 만들어요 |
| 그룹 | 그룹방 | 서로의 오늘이 동기가 돼요 | 공지부터 집중 기록까지 한 화면에서 |
| 그룹 | 만들기 | 마음 맞는 사람과 지금 시작해요 | 우리에게 꼭 맞는 집중 그룹 만들기 |
| 챌린지 | 진행 | 누가 먼저 목표에 닿을까요? | 오늘의 진행률을 함께 보고 응원해요 |
| 챌린지 | 설정 | 지키고 싶은 시간을 목표로 만들어요 | 집중과 스크린타임, 원하는 방식 그대로 |
| 챌린지 | 내기 | 약속에 코인을 걸고 끝까지 해내요 | 달성한 사람끼리 적립금을 나눠 가져요 |
| 누끼 | 선택 | 세상에 하나뿐인 내 그로몬 | 좋아하는 물건을 나만의 캐릭터로 |
| 누끼 | 사진 | 찍거나 고르면 바로 캐릭터로 | 사진 한 장으로 시작하는 간단한 만들기 |
| 누끼 | 완료 | 오리고, 표정을 더해 완성! | 평범한 물건이 살아 움직이는 순간 |
