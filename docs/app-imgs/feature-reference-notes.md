## 이미지 구성에 반영한 핵심

- 그룹: 단순 랭킹이 아니라 `함께하는 공간`으로 보이도록 목록 → 그룹방 → 만들기 순서로 구성했다.
- 챌린지: PRD의 핵심인 `공동 목표`, `멤버 전원 진행 공개`, `코인 에스크로 내기`를 각각 한 장에 분리했다.
- 누끼: 기능을 바로 이해할 수 있도록 `선택 결과` → `사진 입력` → `캐릭터 완성`의 짧은 전환으로 구성했다.
- 모든 최종 화면은 실제 iPhone 15 Pro Max 시뮬레이터 캡처다. 생성형 이미지로 앱 UI를 재구성하지 않았다.
