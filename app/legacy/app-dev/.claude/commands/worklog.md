`app/.claude/$1_WorkLog.md` 파일을 새로 생성하세요. (입력: $ARGUMENTS)

`app/.claude/ScreenTime_WorkLog.md`를 참고해서 같은 톤/구조로 아래 섹션을 가진 템플릿을 작성합니다. 코드 변경 전이라면 각 섹션은 빈 틀로 두고, 작업하면서 계속 채워나가는 용도입니다.

```markdown
# Gromo $1 개발 Work Log

## 개요

(전달받은 설명을 바탕으로 1~2줄 요약. 설명이 없으면 "TODO: 기능 설명 작성")

---

## 아키텍처 / 설계 결정

(구조도, 주요 설계 결정과 그 이유 — 작업 진행하며 채우기)

---

## 코드 변경 사항

(파일별 변경 내용 — 작업 진행하며 채우기)

---

## 트러블슈팅 히스토리

(문제 → 원인 → 해결 형식으로 기록)

---

## 빌드 / 배포 주의사항

---

## 체크리스트

- [ ]

---

**최종 업데이트**: (오늘 날짜)
```

파일 생성 후, CLAUDE.md의 "📓 기능 개발 Work Log" 규칙(기능이 안정화되면 "📚 문서 네비게이션"에 추가)을 짧게 안내하세요.
