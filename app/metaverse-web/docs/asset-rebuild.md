## 생성 방법

- 모든 모델은 저장소 안의 TypeScript 코드로 만든 절차적 geometry다. Three.js 기본 도형(구·원기둥·원뿔·회전체·관·압출)을 변형하고, 부품을 정점 색이 있는 geometry 하나로 합친다(`assets3d/geometry.ts`의 `Builder`).
- 같은 시드는 같은 결과를 낸다(`rng`, `fbm`). 새로 고쳐도 섬 배치가 바뀌지 않는다.
- 외부 모델·텍스처·생성형 이미지 도구를 쓰지 않았다. 내려받은 파일, 유료 결제, 외부 업로드가 없다. `public/models`, `public/textures`에는 파일을 추가하지 않았다.
- 텍스처는 실행 중 canvas로 그리는 작은 원형 그라데이션 두 장(고양이 그림자, 불티)뿐이다.
- 색은 앱 원화(`app-dev/src/assets/redesign/cat-black.png`, `cat-black-sitting.png`, `island-whole-warm.jpg`, `bld-hall.png`, `bld-shop.png`, `bld-mailbox.png`)를 보고 정했다. UI 의미 색은 `theme.ts`를 그대로 쓰고, 목재·잎·바다 같은 재질 색만 `assets3d/palette.ts`에 둔다.

## 배치 기준

- `layout.ts`를 읽기만 한다. 섬 반지름 22/20.4, 모닥불 (0,0), 30개 좌석, 건물, 나무, 부두·스폰 좌표를 그대로 쓴다.
- 걷는 타원 안은 높이 `GROUND_Y`(0.1)로 평평하다. 그 밖에서 모래 비탈이 물가(`shoreRadius` 23.3)까지 내려가고 물속으로 이어진다. 고양이가 걷는 곳은 모두 물 위로 나와 있다.
- 광장(반경 10.1)은 흙바닥이다. 모닥불 둘레(3.6)와 의자 두 줄 사이(7.1)에 돌길 고리가 있다. 길은 회관·상점·등대·우체통·부두와 동서 해변 오솔길로 이어진다.
- 부두 판자는 x ±1.7, z 17.5~26.05다. `world.ts`의 부두 걷기 범위(|x|<1.5, 18≤z<25.3)를 덮는다.
- 건물 바로 옆 나무(회관 2.6m, 등대 1.9·2.0m)는 위치·충돌은 그대로 두고, 수관이 건물에 박히지 않게 어린 나무로 줄였다(`site.ts`의 `TREES`).

## 고양이

- 한 마리가 skinned mesh 하나(draw call 1)다. 뼈 17개(엉덩이·가슴·머리·눈·눈동자·귀 2·팔 2·다리 2·꼬리 3·낚싯대·책)에 부품을 묶었다. 몸통과 꼬리는 이웃 뼈와 가중치를 섞어 부드럽게 굽는다.
- geometry는 털색·내 고양이 여부별로 한 번 만들어 공유한다. 재질은 모든 고양이가 하나를 쓴다.
- 자세: idle(숨쉬기·고개 갸웃·둘러보기·눈 깜빡임·귀 떨림·꼬리 물결), walk(이동 거리로 진행하는 걸음·팔 흔들기·몸 들썩임), wave(오른팔 들어 흔들기), sit(바닥에 앉아 다리 뻗기·꼬리 옆으로), fish(앉아서 낚싯대·줄·찌, 가끔 찌가 당겨짐), focus(의자 좌판 0.46에 앉아 책 들기, 다리를 좌판 앞으로, 꼬리를 좌판 옆으로 늘어뜨림).
- 모든 동작은 `useFrame`에서 뼈를 바꾼다. 프레임마다 React 상태를 갱신하지 않는다. 원격 고양이 위치 보간은 시작 위치만 prop으로 두는 기존 방식을 유지했다.
- `reduced=true`면 반복 동작(숨쉬기·깜빡임·꼬리·찌)을 멈추고 자세는 즉시 바뀐다.
- props 계약(`actor`, `local`, `label`, `reduced`)은 그대로다. `actor.action === "focus"`면 앉고, 위치·방향은 좌석 좌표와 `yaw`를 따른다.

## 의자(`FocusSeats`)

- `FocusSeats({ occupied, activeSeatId, pendingSeatId, onSelect })`. 30개를 인스턴싱 메시 2개(틀·쿠션)로 그린다.
- 클릭 범위는 의자와 앉은 고양이 아랫부분을 덮는 보이지 않는 상자(재질 `visible: false`, 그리지 않고 광선만 맞는다)다.
- 클릭: `delta > 6`은 무시, 의자를 맞으면 `stopPropagation()`. 다른 고양이가 쓰는 의자(`occupied.has(id) && id !== activeSeatId`)는 선택하지 않는다. `onPointerMissed`는 쓰지 않는다.
- 상태 구분: 빈 의자 크림 쿠션, 사용 중 하늘색 쿠션, 내 자리 분홍 쿠션과 분홍 고리, 앉는 중 버터색 쿠션과 끊어진 고리(움직이지 않음), 호버는 쿠션이 밝아지고 흰 고리와 커서(`pointer`, 사용 중이면 `not-allowed`).
- 이름표는 호버한 의자 하나에만 띄운다: 「N번 자리 · 비어 있음/내 자리/앉는 중/○○ 집중 중」. N은 `id + 1`이다.

## 바다

- 섬 아래(반경 12)부터 반경 420까지의 극좌표 메시 하나에 셰이더를 쓴다. 물가 근처만 0.3m 간격으로 촘촘하다.
- 지형과 바다가 같은 해안 단면 식(`shoreline.ts`)을 공유한다. GLSL은 TypeScript 상수에서 생성하므로 해안선·수심·포말 위치가 지형과 어긋나지 않는다.
- 수심으로 색을 섞는다: 얕은 곳은 반투명이라 물속 모래가 비치고, 깊어질수록 짙은 청록, 멀리는 장면 안개 색으로 녹아든다.
- 파도: 방향이 다른 사인파 네 개의 기울기와 잔물결 노이즈로 법선을 만들고, 큰 노이즈로 지역마다 세기를 바꿔 같은 방향 줄무늬가 반복되지 않게 했다. 노이즈는 옥타브마다 좌표를 돌려 격자 무늬가 없다.
- 반짝임: 태양 반사광과 천천히 움직이는 성긴 점. 카메라에서 멀수록 잔물결과 반짝임을 줄여 화면이 끓지 않게 했다.
- 물가 포말: (1) 물가선의 젖은 띠는 물이 밀려올 때 넓어지고 빠질 때 가늘어진다. (2) 바다 쪽에서 물결 띠가 물가로 다가오며 끊기고, 물가에서 사라진다. (3) 물가 근처 수면 전체가 천천히 오르내려 물가선이 모래 비탈을 오르내린다.
- 바위·부두 기둥·나룻배 둘레에 숨 쉬듯 커졌다 작아지는 포말 고리를 그린다.
- 땅 위는 지형이 수면보다 높아 깊이 시험으로 가려진다. 물이 땅 위에 그려지지 않는다.
- `reduced=true`면 시간을 6.4초에 고정한 정지 수면이다(포말 띠가 보이는 순간).

## 성능 구조

- 고양이 한 마리당 draw call 2개(몸 1, 바닥 그림자 1, 내 고양이는 고리 1 추가).
- 의자 30개 2개, 풀·꽃·덤불·고사리·돌길·조약돌·바위 인스턴싱 13개, 지형 1개, 바다 1개.
- 나무 29그루와 건물 4채는 카메라를 가리면 옅어져야 해서(`CameraOcclusion`이 재질 불투명도를 바꿈) 그루·채마다 재질을 따로 둔다. geometry는 종류별로 공유한다.
- 풀·꽃·덤불·나무 흔들림은 정점 셰이더가 처리한다. CPU는 프레임마다 바람 시간 하나만 넘긴다.
- 로컬 Chromium(1440×900, coordinator 연결 상태의 실제 앱)에서 약 60fps, 콘솔 오류 0건을 확인했다. 기기 성능 보증은 아니다.

## 제약과 남은 일

- 회관·등대에 붙은 나무 세 그루는 어린 나무로 줄여 겹침을 피했다. 큰 나무로 두려면 `layout.ts`의 `TREE_POSITIONS`에서 건물 3m 안의 나무를 빼야 한다(coordinator 결정).
- 번들 크기가 기존 경고 기준(1,200kB)을 조금 넘는다. 기능 문제는 없으며 기준은 `vite.config.ts`(coordinator 소유)에 있다.
- 장소 이름표는 기존 네 곳(마을회관·강아지 상점·모닥불·낚시 부두)만 두었다. 등대·우체통 이름표는 용어 결정이 필요해 추가하지 않았다.
- 실제 iPhone·Android 기기와 Safari에서는 확인하지 않았다.
