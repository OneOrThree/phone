---

작업 디렉토리는 `app/`입니다. 아래 순서로 진행하세요.

1. `npm run lint`와 `npm run format:check`를 실행
2. 에러/경고가 있으면 **자동으로 고치지 말고** 결과를 요약해서 보여주고, `lint:fix` / `format:fix` 실행 여부를 사용자에게 확인받기
3. 검사를 통과했다면 `git status`, `git diff`로 변경 내역 확인
4. 변경 내역을 바탕으로 커밋 메시지를 `<태그>: <한국어 설명>` 형식으로 1~2개 추천 (예: `feat: 로그인 화면 UI 추가`)
5. **`git commit`, `git push`는 절대 실행하지 않음** — 항상 사용자가 직접 실행
