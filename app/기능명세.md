# Gromo 기능 명세서

- 목적: 화면·기능 정의서
- 플랫폼: iOS 우선
- 재화: 코인 단일 (현금 충전 불가)
- 화면 명세 템플릿: 목적 / 구성 요소 / 핵심 데이터 / 인터랙션 / 상태·예외

---

## 1. 서비스 개요

### 1.1 정의 & 핵심 가치
- Gromo는 스마트폰 사용을 강제로 차단하지 않고, **덜 쓴 시간을 보상으로 돌려주는** 생산성 앱.
- 핵심 가치: 집중 그 자체가 아니라 **"내 시간이 내 관리하에 있다는 정복감"**.
- 보상은 행동(집중·목표 달성)으로만 얻는 코인으로 캐릭터/방을 꾸미는 데 쓴다.

### 1.2 타겟 & 페르소나 (요약)
- 하루 5시간 이상 스마트폰을 쓰며 자기관리 욕구는 있지만 강제 차단 앱은 답답해하는 1020대(중·고·대학생, 취준생, 사회초년생).
- 페르소나 "진수(24, 대학생)": 폰을 줄이고 싶지만 완전히 끊고 싶진 않음. 얼마나 시간을 되찾고 있는지 보여주는 앱을 원함.

### 1.3 핵심 콘셉트
- 빈 방 + 기본 캐릭터 1종으로 시작 → 코인으로 방·캐릭터를 꾸미고 집중 아이템을 갖춘다.
- **소셜이 핵심:** 집중하다 친구가 궁금해지거나 알림에 끌려 폰을 보게 되는 문제를, "그룹 몰입 세션으로 서로의 상태를 실시간으로 보는" 방식으로 억제한다.
- 핵심 데일리 루프: 앱 진입 → 집중 시작(개인/그룹) → (그룹)그룹원 실시간 상태 확인 → 종료 시 코인·갓생 카드 → 주간 리그 → 주 1회 캐릭터 편지(AI 회고).
- **남은 인생 시간** 콘셉트는 온보딩에서만 1회 노출되는 충격 장치(앱 사용 유도용). 메인 진입 이후 화면에는 등장하지 않음.

## 2. 정보 구조 (IA)

### 2.1 전체 화면 맵
```
[진입]
스플래시 → (신규) 온보딩 / (기존) 로그인·동기화 → 홈

[온보딩 — 최초 1회]
O1 성별·나이 → O2 남은시간 충격 → O3 스크린타임 권한(iOS)
→ O4 전날 스크린타임 → O5 인생 예측 → O6 목표 설정
→ O7 로그인(Apple) → O8 캐릭터 생성·닉네임 → 홈

[메인 — 하단 4탭 + 중앙 FAB]
├─ 홈        : 방 + 캐릭터 · 오늘 요약 · 우편함
├─ 그룹/랭킹 : 세그먼트 [그룹] [리그]
│   ├─ [그룹] 참여 그룹 목록 → 그룹 상세 / 그룹 만들기 / 검색·참가
│   └─ [리그] 자동 편성 30명 주간 랭킹
├─ ● 집중 시작 (중앙 FAB, 풀스크린)
│   └─ F0 카테고리 선택 → F1 개인 집중 ↔(스와이프) F2 그룹 집중 → F3 결과
├─ 상점      : [치장] [가구] [집중 아이템] → 상세·미리보기 → 보유함
└─ 마이      : 목표 변경 / 기록 보기(주·월·년) / 권한 / 계정

[오버레이]
N1 AI 주간 편지 (발행일 1회성 알림) · 홈 우편함에 영구 보관
```

### 2.2 하단 탭
- 4탭 + 중앙 FAB 구성: `홈 · 그룹/랭킹 · (● 집중 시작) · 상점 · 마이`
- 집중 시작은 탭이 아닌 중앙 FAB. 누르면 F0 카테고리 선택으로 진입(풀스크린, 탭바 숨김).
- 세계 랭킹은 폐기, 친구 랭킹 별도 화면 없음(그룹원 목록 + 리그로 흡수).

## 3. 핵심 사용자 플로우

- 온보딩: 성별·나이 → 충격(남은시간·인생예측) → 권한·전날 사용 자각 → 목표 설정 → 로그인 → 캐릭터 → 홈
- 집중: FAB → 카테고리 선택 → 개인 집중(기본), 좌우 스와이프로 그룹 집중 → 종료 → 결과·공유 → 홈
- 보상: 집중 시간 / 스크린타임 목표 달성 / Streak / 그룹 챌린지 달성 → 코인 → 상점에서 꾸미기·집중 아이템
- 그룹/리그: 그룹 생성(챌린지 지정) → 그룹원과 앰비언트 집중 → 주간 누적 몰입이 리그 점수 → 주말 승격/강등

## 4. 화면별 기능 명세

### 4.1 온보딩
공통: O1~O8 상단 진행 인디케이터, 좌상단 뒤로가기.

**O1. 성별·나이 입력**
- 목적: 남은 시간(기대수명) 계산용 최소 정보 (국가·기타 정보 수집 안 함)
- 구성: 타이틀, 성별 칩(남/여), 나이 입력, [다음]
- 데이터: 성별, 나이
- 인터랙션: 선택·입력 → 다음
- 상태·예외: 미입력 시 [다음] 비활성, 나이 범위 유효성

**O2. 남은 시간 충격 (1회성)**
- 목적: 남은 인생 시간을 대형 숫자로 각인
- 구성: 대형 숫자(예 490,560시간 / 20,440일) + 연출, 설명 문구, [다음]
- 데이터: (기대수명 − 현재나이) 환산값
- 상태·예외: 계산 로딩

**O3. 스크린타임 권한 요청 (iOS)**
- 목적: 사용 데이터 수집 동의 (iOS Screen Time / FamilyControls)
- 구성: 필요 이유·수집 항목 안내, [권한 허용] → 시스템 시트, [나중에]
- 인터랙션: 허용 → 시스템 다이얼로그
- 상태·예외: 허용 → O4 / 거부 → "핵심 기능 제한" 안내 후 O4(데이터 없이 진행)
- 메모(iOS): Screen Time 권한은 원시 수치를 자유롭게 읽기 어렵고 샌드박스 리포트 형태. O4 데이터 표현은 개발 단계 제약 가능 — 와이어프레임은 이상적 형태로 작성.

**O4. 전날 스크린타임 확인**
- 목적: 어제 사용량으로 현실 자각
- 구성: 총 사용시간 대형 표시(예 8시간 12분), 카테고리 분해(SNS·영상·메신저·기타), [다음]
- 데이터: 전날 총/카테고리별 스크린타임
- 상태·예외: 권한 거부/데이터 없음 → 예시값 또는 수동 입력, 로딩

**O5. 남은 인생 기준 예측**
- 목적: 현재 패턴 지속 시 폰에 쓸 시간 환산(충격 강화)
- 구성: 환산 문구 + 시각화(막대/도넛), [다음]
- 데이터: 전날 사용률 × 남은 시간

**O6. 목표 스크린타임 설정**
- 목적: 하루 목표 사용시간 확정(보상 기준선)
- 구성: 목표 슬라이더, 실시간 환산(현재 vs 목표 / 절약 가능), AI 추천 목표 칩, [설정 완료]
- 데이터: 목표 시간, 절약 환산
- 상태·예외: 비현실적으로 낮은 목표 시 경고

**O7. 로그인**
- 목적: 소셜·랭킹·기록을 묶을 서버 계정 생성. 앞서 입력한 정보를 계정에 바인딩
- 구성: 로고·한 줄 카피, [kakao로 계속하기], 약관·개인정보 동의
- 인터랙션: kakao 로그인 시트
- 상태·예외: 취소/실패 재시도, 기존 계정이면 데이터 복원·동기화
- 연결: → O8

**O8. 캐릭터 생성·닉네임**
- 목적: 기본 캐릭터 + 빈 방 부여, 표시 이름 설정
- 구성: 캐릭터 등장 연출, 빈 방 배경, 닉네임 입력, [시작하기]
- 데이터: 기본 캐릭터, 닉네임
- 인터랙션: 닉네임 입력 → 시작 → 홈
- 상태·예외: 닉네임 길이/중복

### 4.2 홈
- 목적: 내 방 + 캐릭터를 보여주는 메인 화면, 오늘 상태 요약
- 구성:
  - 상단 바: 프로필 썸네일·닉네임, **코인 잔액** (콕찔림은 OS 푸시)
  - 중앙: 방 + 기본 캐릭터 + 장착 가구/소품 (탭 시 꾸미기/상점 진입), **우편함 오브젝트**
  - 오늘 요약 카드: 목표 사용시간 / 현재 사용시간 / 오늘 집중시간 / 목표 달성 진행도
  - 하단: 글로벌 탭바(+ 중앙 ● 집중 시작 FAB)
- 핵심 데이터: 오늘 스크린타임·목표, 누적 집중시간, 코인, 장착 아이템, 새 편지 여부
- 인터랙션: 방/캐릭터 탭(꾸미기), 우편함 탭(편지함), 요약 카드 탭(기록 이동), FAB(집중 시작)
- 상태·예외: 로딩 / 스크린타임 권한 없음(사용시간 영역 제한) / 빈 방 기본 상태 / 새 편지 도착 시 우편함 뱃지

### 4.3 집중(포커스) 모드
공통: 풀스크린(탭바 숨김), 좌상단 뒤로가기.

**F0. 집중 시작 — 카테고리 선택**
- 목적: "무엇에 집중할지"를 사용자 정의 카테고리에서 선택
- 구성: 좌상단 뒤로가기, 내 카테고리 리스트(카드 = 카테고리명 · 지정 액션 아이템 아이콘 · **누적 집중시간**), [+ 새 카테고리 만들기], (선택)목표 시간, [집중 시작]
- 카테고리 생성/편집: 이름 입력 + 액션 아이템 지정(보유 아이템 중 선택, 미보유 시 상점 유도). 기본 제공은 '공부(책)' 1종
- 데이터: 카테고리 목록·누적 집중시간, 지정 아이템, 보유 아이템
- 인터랙션: 카테고리 선택→시작, 새로 만들기/편집, 아이템 지정
- 상태·예외: 카테고리 0개(첫 사용 시 기본 '공부' 자동 제공) / 미보유 아이템 지정 → 상점 이동

**F1. 개인 집중 화면 (기본)**
- 목적: 혼자 집중. 캐릭터가 선택 카테고리의 액션 아이템 모션으로 작업
- 구성: 좌상단 뒤로가기, 내 방 + 캐릭터(기본 = 책 펴고 공부 / 노트북·요가매트·아령 등은 구매 후 사용), 타이머(경과/목표), 카테고리명, 적립 예정 코인, 스와이프 힌트(→ 그룹)
- 데이터: 경과·목표 시간, 카테고리, 적립 코인
- 인터랙션: 정지/종료, 스와이프 → 그룹
- 상태·예외: 진행 / 일시정지 / 목표 도달 / 앱 이탈 시 집중 중단 판정

**F2. 그룹 집중 화면 (스와이프)**
- 목적: 내가 집중하는 동안 같은 그룹원의 실시간 상태를 한 화면에서 봄(앰비언트). 서로 보는 것 자체가 이탈 억제
- 구성: 좌상단 뒤로가기, 그룹원 방을 붙인 **타일 뷰**(각 칸 = 캐릭터 + 상태: 몰입/휴식/이탈), 내 타이머 상주, 이탈 그룹원 [콕 찌르기], 그룹·챌린지 헤더
- 데이터: 그룹원별 실시간 상태·집중시간, 챌린지 목표, 내 진행
- 인터랙션: 콕 찌르기(→ 같은 그룹원에게 OS 푸시 알림), 그룹원 탭(상세), 스와이프 ← 개인
- 상태·예외: 온라인 그룹원 0명(빈 상태) / 실시간 연결 끊김 / 이탈 시 해당 칸 캐릭터 잠듦·휘청

**F3. 세션 종료 / 결과 화면**
- 목적: 결과 정산 + 공유 동기
- 구성: 이번 세션 카테고리, 총 집중시간, 획득 코인, Streak 갱신, 카테고리별 누적 집중시간 미니, (그룹)전원 완료 여부 + 그룹원 리액션 이모지, [갓생 카드 공유], [확인 → 홈]
- 인터랙션: 이모지 리액션, 갓생 카드 생성·인스타 스토리 1탭 공유, 확인
- 상태·예외: 목표 미달 / 그룹 일부 미완료 / 공유 취소

**이탈 감지 (F1·F2 공통)**
- 앱 포그라운드 모니터링 → 화면 이탈(앱 스위치·백그라운드) 실시간 감지
- 이탈 시: 그룹원 화면에서 내 캐릭터 잠듦/휘청 + 본인 집중 중단 판정, 강제 탈락 없음(소셜 압박만)
- 메모(iOS): '화면 이탈' 여부만 감지, 타 앱 내용은 모름. 백그라운드 측정·실시간 동기화는 기술 검증 필요.?? 아마 안될거같기도

### 4.4 그룹 / 랭킹
**G0. 탭 진입**
- 상단 세그먼트 [그룹] [리그], 기본 진입 [그룹]. 접속만(집중 자동 시작 아님)

**G1. 그룹 — 목록**
- 목적: 참여 중 그룹 보기 / 만들기 / 검색·참가
- 구성: 참여 그룹 리스트(카드 = 그룹명 · 챌린지 종류 · 인원 · 현재 몰입 중 인원), [+ 그룹 만들기], [그룹 검색·참가]
- 인터랙션: 그룹 탭 → G2, 만들기 → G3, 검색·참가
- 상태·예외: 그룹 0개 빈 상태

**G2. 그룹 상세**
- 목적: 그룹원 정보·기록 열람(집중 화면 아님, 열람 전용 — 콕 찌르기 없음)
- 구성: 그룹 헤더(이름·챌린지·기간), 그룹원 목록(캐릭터·닉네임·오늘/누적 집중시간·상태), 챌린지 달성 현황, (방장)그룹 설정
- 인터랙션: 그룹원 탭(프로필), (방장)설정·초대, 나가기
- 상태·예외: 비방장 권한 제한 / 챌린지 진행·종료

**G3. 그룹 만들기**
- 목적: 그룹 생성 + 챌린지 지정(생성 시 1회)
- 구성: 그룹명, 챌린지 유형 — ⓐ 목표 N시간 누적 몰입 / ⓑ 특정 시간대(s~e) 핸드폰 안 보기, 인원 한도, 공개/비공개, 친구 초대
- 인터랙션: 유형 선택, 파라미터 설정, 생성
- 상태·예외: 유료 옵션(인원 확장·커스텀·벌칙)은 구분 표시

**G4. 리그 (Duolingo식)**
- 목적: 유사 수준 30명 소그룹의 주간 누적 몰입시간 경쟁
- 구성: 리그 티어, 30명 순위 리스트(순위·닉네임·주간 누적 몰입·증감), 내 위치 하이라이트, 승격/강등 구간 라인, 주간 마감 카운트다운
- 인터랙션: 유저 탭(프로필), 순위 갱신
- 상태·예외: 자동 편성(별도 참가 없음) / 주말 마감 → 승격·강등 연출 / 신규 배치 중

### 4.5 상점
**S0. 상점 진입**
- 목적: 카테고리별 아이템 둘러보기·구매·미리보기
- 구성:
  - 상단: 코인 잔액
  - 대분류 세그먼트: [치장] [가구] [집중 아이템]
  - 소분류 칩: 치장(머리/상의/하의/신발) · 가구(침대/책상/의자/카펫) · 집중 아이템(소분류 없음)
  - 아이템 그리드: 셀 = 썸네일·이름·**가격 배지(코인 수량 / 현금 ₩)**·(보유 시 '보유')
- 인터랙션: 대분류 전환, 소분류 칩 필터, 아이템 탭 → S1
- 상태·예외: 로딩 / 네트워크 오류 / 소분류 빈 상태

**S1. 아이템 상세 · 미리보기**
- 목적: 구매 전 내 방·캐릭터에 적용해보고 결정
- 구성: 미리보기(방/캐릭터 적용 모습), 아이템 정보(이름·소분류·설명), 가격, [미리보기 적용], [구매], (보유 시)[장착]
- 인터랙션: 미리보기 토글, 구매(코인 차감 / 현금 결제 시트), 장착
- 상태·예외: 코인 부족(집중 유도 안내) / 현금 결제 취소·실패 / 이미 보유 → 장착 전환

**S2. 보유함 / 장착**
- 목적: 보유 아이템 관리·장착
- 구성: 대·소분류별 보유 목록, 장착 상태, [장착/해제]
- 인터랙션: 장착/해제, 집중 아이템 → 카테고리에 지정(4.3 F0 연동)
- 상태·예외: 미보유 빈 상태

**가격 규칙**
- 치장(머리·상의·하의·신발): 코인 또는 현금 전용 혼재 (그리드 배지로 구분)
- 가구(침대·책상·의자·카펫): 코인 또는 현금 전용 혼재
- 집중 아이템: **코인 전용**(기본 '책' 무료), 현금 불가

### 4.6 마이페이지
**M0. 마이페이지 (메인)**
- 구성: 프로필(캐릭터·닉네임), 코인 잔액, 메뉴 — [목표 설정 변경] · [기록 보기] · [권한 관리] · [계정 설정]

**M1. 목표 설정 변경**
- 구성: 현재 목표, 슬라이더, (선택)AI 추천, [저장]
- 상태·예외: 적용 기준일 안내(접속 기준 전날부터)

**M2. 기록 보기**
- 구성: 기간 세그먼트 [주][월][년], 지표(평균 스크린타임 / 목표 달성률 / 누적 집중시간 / Streak), 그래프, 카테고리별 집중 비중
- 인터랙션: 기간 전환, 드릴다운
- 상태·예외: 초기 데이터 부족 빈 상태 / 권한 없음 시 스크린타임 지표 제한

**M3. 권한 관리**
- 구성: 스크린타임(iOS)·알림 권한 상태와 토글, 미허용 시 설정 유도

**M4. 계정 설정**
- 구성: 닉네임 변경, 로그아웃, 회원 탈퇴, 약관·개인정보
- 상태·예외: 탈퇴 확인 모달

### 4.7 알림 & 우편함
**N1. AI 주간 편지 (1회성 알림)**
- 발행일에 앱 진입 시 1회 표시. 캐릭터가 보낸 편지 형식(몰입 취약 시간대 + 집중 패턴 진단 + 다음 주 동기부여)
- [닫기] 후엔 홈 우편함에서만 다시 열람
- 상태·예외: 미발행일 미노출

**홈 우편함**
- 방 안 우편함 오브젝트 → 탭 시 편지함(과거 편지 목록 → 상세). 새 편지 도착 시 뱃지/연출

## 5. 공통 시스템 / 규칙

### 5.1 재화 & 보상 (코인 단일)
- 단일 재화 = 코인, 현금 충전 불가
- 획득 경로: ① 포커스 집중 시간 비례(개인/그룹) · ② 스크린타임 목표 달성(접속 기준 전날 사용 < 온보딩 목표 → 지급, 초과 → 미지급) · ③ 연속 Streak 보너스 · ④ 그룹 챌린지 달성(+벌칙 정산: 실패자→성공자)
- 사용처: 코인 전용 집중 아이템, 코인가 치장·가구
- 불가: 현금 충전, 집중 기능·성취 구매

### 5.2 캐릭터 (성장 폐지)
- 기본 캐릭터 1종. 레벨·크기 변화 없음.
- 외형은 치장 아이템 장착으로만 변함.

### 5.3 아이템
- 분류: 치장(머리/상의/하의/신발) · 가구(침대/책상/의자/카펫) · 집중 아이템(노트북/요가매트/아령 등)
- 획득: 코인 구매 / 현금 전용(치장·가구 한정) / 기본 무료(집중 '책'). **랜덤 희귀템 발견 없음.**
- 집중 아이템 ↔ 카테고리 연동: 카테고리에 지정 시 집중 모드 캐릭터 모션 결정(4.3 F0)
- 장착: 치장·가구는 방·캐릭터 외형. 미리보기 후 장착

### 5.4 Streak & 업적
- Streak: 연속 참여일. 결과·홈 표시, 코인 보너스, 리그 반영
- 업적 뱃지(유지): 첫 목표 달성 / 연속 N일 / 누적 집중시간 / 어제보다 줄이기 등. 달성 시 코인 보상

### 5.5 리그 산정
- 자동 편성, 유사 수준 30명
- 점수 = 주간 누적 몰입 시간(포커스 모드 측정)
- 주말 마감 → 상위 승격 / 하위 강등(경고)
- (미정) 티어 단계 수

### 5.6 이탈 감지 / 행동 검증
- 앱 포그라운드 모니터링, 화면 이탈(앱 스위치·백그라운드) 실시간 감지
- 이탈 시: 그룹원 화면에서 캐릭터 잠듦/휘청 + 본인 집중 중단 판정. 강제 탈락 없음
- iOS 제약: '화면 이탈' 여부만 감지, 타 앱 내용은 모름. 백그라운드 측정·실시간 동기화 기술 검증 필요

### 5.7 AI 기능
- AI 목표 추천: 최근 사용·달성률 기반 현실적 목표 제안 (O6, M1)
- AI 주간 편지(회고): 주 1회, 캐릭터 편지 형식 — 몰입 취약 시간대 + 집중 패턴 유형 + 다음 주 동기부여. 발행 시 1회 알림(N1) + 홈 우편함 보관
- **AI 하루 회고 없음**(주간으로 통합)

## 부록 A. 방 비주얼 방향 (검토 중)

두 방향 중 결정 예정. 와이어프레임 단계에서 화면 구성·꾸미기 단위가 달라진다.

### 옵션 1 — 아이소메트릭 (별도 파일: Gromo_방_옵션1_아이소메트릭.svg)
- 방 = 벽 2 + 바닥 1의 3면 아이소메트릭.
- 개인 집중: 내 방 1개.
- 그룹 집중: 같은 방을 타일처럼 붙여 그룹원 상태(몰입/휴식/이탈)를 한 화면에.
- 꾸미기 단위: 방 안 가구·바닥·벽면 오브젝트.
- 장점: 공간감·꾸미기 깊이 큼 / 단점: 아트·구현 비용, 타일 정렬 복잡.

### 옵션 2 — 평면 벽 + 한 공간 집중
- 개인 집중: 평면 벽(정면) 방. 캐릭터가 벽 앞에서 작업.
- 그룹 집중: 그룹원들이 **한 공간(공유 룸)에 함께 모여** 집중.
- 벽 테마 설정 가능: 도서관, 카페 등 — 꾸미기/과금 단위가 '벽 테마' 중심.
- 장점: 구현·아트 단순, '함께 있는' 일체감 강함 / 단점: 개인 방 꾸미기 깊이는 상대적으로 얕음.

### 비교 요약
- 꾸미기 단위: 옵션1 = 방 안 오브젝트 / 옵션2 = 벽 테마(공간 단위)
- 그룹 표현: 옵션1 = 방 타일링 / 옵션2 = 한 공간에 캐릭터 모임
- 구현 난도: 옵션1 > 옵션2
