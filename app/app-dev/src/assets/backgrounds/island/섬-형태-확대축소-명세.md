# 확정 6번 섬 표시 명세

- 월드 크기: 1536 × 1024px
- 원본 종횡비를 유지하고 화면에는 카메라 확대·이동으로 표시한다.
- 섬, 시설 레이어, 캐릭터 좌표에는 항상 같은 카메라 변환을 적용한다.
- 기본 카메라 중심은 `(768, 512)`, 기본 가시 폭은 1200px이다.
- 지형 밖 바다와 해변 방향으로 보행 경로를 만들지 않는다.
- 전망대는 왼쪽 위의 분리된 섬에 있으며 다리로만 연결된다.
- 집중섬과 낚시섬은 별도 배경이며 이 월드 교체의 영향을 받지 않는다.
- 정확한 시설 좌표는 `placement.json`, 월드 메타데이터는 `world.json`을 따른다.
