# 바다 첫 만남 온보딩

로그인과 고양이 선택을 먼저 마치고, 누워 있던 고양이의 질문에 이름을 입력한다.
첫 대화는 친구를 만나고 함께 지낼 섬을 기대하는 이야기로 이어진다.
망원경에서 목적지를 고르면 설치 후 첫 이동은 약 5초의 바다 체험으로 연결한다.
`SeaScene`에 목업 고양이 한 명과 바다 만남 안내를 표시하고 `intro-arrivals` API로 실제 도착을 처리한다.
완료 키는 AsyncStorage에만 저장해 재설치하면 다시 체험할 수 있다. 첫 이동 목록에는 섬 이름만 표시한다.
도착 성공 전에는 완료하지 않고 계정별 의도 키를 저장해 응답 유실·재시작에도 재사용한다.
이후 이동은 기존 `focus.startSea` 명령으로 집중을 시작한다.

## 화면과 체크포인트

승인 시안 20장 중 로그인은 `LoginScreen`, 2~17은 `OnboardingFlow`,
18~20은 기존 `SeaVoyageHost`/`SeaScreen`의 집중·한마디 입력·표시 상태다.

- `intro`: 고양이 선택과 첫 대화 구간이다.
- `scope`: 첫 대화가 끝나고 목적지를 고르는 구간이다.
- `done`: 첫 항해 체험은 실제 섬 도착 성공 후, 일반 항해는 실제 출발 성공 후다. 한마디 작성은 완료 조건이 아니다.
- 일반 섬 집중·휴식을 복구한 것만으로는 스토리를 완료하지 않는다. 다른 기기에서 소속이 이미 생겼으면 오래된 이야기는 재개하지 않는다.
- 진행 세션은 기존 서버 복구가 우선한다. 목적지 변경·중복 요청·응답 유실은 기존 세션 명령 계층이 처리한다.

이 체크포인트는 기존 계정 귀속 로컬 저장본 안에 있다. 재설치·다른 기기까지 스토리 진행도를
동기화하는 새 서버 계약은 추가하지 않았다. 프로필 등록이 끝난 계정은 이야기 기록과 관계없이
현재 섬이 없으면 바다로 진입·복귀한다. 예전 버전에서 프로필을 마치지 않은 계정은
새 온보딩을 진행한다. 완료 후 섬에 가입하지 않고 집중을 마쳐도 바다의 표류 상태로 돌아온다.
예전 첫 섬 선택 화면은 삭제했으며, 섬 없는 사용자는 바다에서 망원경을 눌러 목적지를 찾는다.

## 에셋과 미리보기

실제 집중 바다를 cover로 사용한다. 고양이·주황 뗏목·승인 v5 섬은
`src/assets/ota/onboarding/`에 보관한다. 여섯 색의 일부 자세는 승인 HTML과 같은 대체 자세다
(치즈·크림·회색 첫 자세는 loaf, 검정 외 망원경은 앉은 자세).
망원경은 `ISLAND_STAGE_ART`와 서버의 주민 수·완공 건물 수로 집 0·1·3·5채를 표시한다.
기존 섬 목록이 비었거나 들어갈 섬이 없으면 서버가 마련한 15분 무인도 하나를 보여준다.
정원이 남은 섬이나 이미 가입한 섬이 있으면 기존 목록·순서를 유지하고 예약 무인도는 숨긴다.
소속이 없는 사용자도 같은 기준을 쓰며, 소속이 없다는 이유로 무인도를 우선하지 않는다.
무인도는 출발 전 가입하지 않으며 실제 도착 후 내 새 섬으로 정착한다. 첫 항해 체험은 집중 정산 없이 서버가 새 섬을 생성한다.

`npm run web -- --port 18866` 후 `http://localhost:18866/?onboarding`은 API를 쓰지 않는 RN 미리보기다.
실제 사용자 경로는 `character` 라우트이며, 프로필 저장과 섬 목록·출발 요청을 서버에 연결한다.
`?onboarding=uninhabited`는 바다 → 기존 망원경 → 무인도 항해를 검토한다.
`?onboarding=islands`는 소속 없는 사용자에게도 기존 섬 목록(정원 찬 섬 포함)이 보이는 경우다.
`?onboarding=full`은 기존 섬이 모두 정원이 차서 무인도 하나가 보이는 경우다.
