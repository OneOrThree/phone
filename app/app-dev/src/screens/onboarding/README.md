# 바다 첫 만남 온보딩

로그인과 고양이 선택을 먼저 마치고, 누워 있던 고양이의 질문에 이름을 입력한다.
첫 대화는 친구를 만나고 함께 지낼 섬을 기대하는 이야기로 이어진다.
망원경에서 실제 목적지를 고르면 기존 `focus.startSea` 명령으로 집중을 시작한다.

## 화면과 체크포인트

승인 시안 20장 중 로그인은 `LoginScreen`, 2~17은 `OnboardingFlow`,
18~20은 기존 `SeaVoyageHost`/`SeaScreen`의 집중·한마디 입력·표시 상태다.

- `intro`: 선택 또는 대화 중 종료했으면 선택부터 다시 시작한다. 로그인·저장된 이름·색은 유지한다.
- `scope`: 14번 망원경 안내 이후, 출발 전에 종료했으면 14번 안내부터 다시 시작한다.
- `done`: 실제 출발 성공 후다. 한마디 작성은 완료 조건이 아니다.
- 진행 세션은 기존 서버 복구가 우선한다. 목적지 변경·중복 요청·응답 유실은 기존 세션 명령 계층이 처리한다.

이 체크포인트는 기존 계정 귀속 로컬 저장본 안에 있다. 재설치·다른 기기까지 스토리 진행도를
동기화하는 새 서버 계약은 추가하지 않았다. 로컬 진행도가 없는 프로필 완료 계정은 기존 경로로 진입한다. 예전 버전에서 프로필을 마치지 않은 계정도
새 온보딩을 진행한다. 완료 후 섬에 가입하지 않고 집중을 마치면 바다의 표류 상태로 돌아온다.

## 에셋과 미리보기

실제 집중 바다를 cover로 사용한다. 고양이·주황 뗏목·승인 v5 섬은
`src/assets/ota/onboarding/`에 보관한다. 여섯 색의 일부 자세는 승인 HTML과 같은 대체 자세다
(치즈·크림·회색 첫 자세는 loaf, 검정 외 망원경은 앉은 자세).
망원경 API에 건물 단계가 없어 승인 v5의 공통 삽화를 사용한다.

`npm run web -- --port 18866` 후 `http://localhost:18866/?onboarding`은 API를 쓰지 않는 RN 미리보기다.
실제 사용자 경로는 `character` 라우트이며, 프로필 저장과 섬 목록·출발 요청을 서버에 연결한다.
