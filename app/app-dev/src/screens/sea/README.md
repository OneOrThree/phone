# 먼바다 화면

## 구현 범위

`SeaScreen`은 서버 정본을 전달받는 화면이다. 실제 세션 API를 대신하거나 로컬에서
보상을 지급하지 않는다. 웹 `?sea`에서 테스트 데이터로 모든 상태를 확인할 수 있다.
`?sea&canvas&stage=focus` / `stage=arrived`는 화면 크기별 비교용이다.

- S1 `1202:907`: 나는 앞에 고정하고 나머지 참여자를 최대 5명씩 탐색.
  10명 방에서는 다른 참여자가 5+4명으로 표시된다. 서버 스냅샷 순서 변경으로
  페이지를 초기화하지 않는다. 화면 밖 독서 모션은 정지한다.
- V1 `1203:1029`: `SeaVoyagePreparation`의 선택적 한마디와 시작 콜백.
- V2 `1203:1071`: 섬 그림 없이 독서 포즈, 과목·도착 정보·시간·진행률, 항해 그만두기.
- V3 `1203:1111`: 도착 전 중도 종료 확인.
- V5 `1203:1194`: 항해 중과 동일한 배치·먼바다를 유지하고 같은 버튼을 섬에 내리기로 교체.
- 결과 `1335:1346`: 섬 이름·정산된 이번 항해 시간·대표 개인 꾸미기 하나. 여러 보상을 받으면 나머지 이름도 함께 표시한다. 사용자 수정대로
  `항해 중 건진 것`, 분류 부제 없음, `섬 둘러보기`를 사용한다.
- G2 `1207:1326`: `SeaDeparture`가 기존 `WorldViews.Sailing`을 재사용한다.
  두 번째부터 건너뛰기 가능. 최초 출항 여부 저장은 호스트가 맡는다.

https://www.figma.com/design/XzlUvx1LGl5OZt6wHr2WRg/new-design?node-id=1357-1347

인계 보드의 참여자 페이지는 `1358:1360` / `1358:1396`,
항해 중·도착 후·결과 예시는 `1358:1471` / `1358:1512` / `1358:1552`다.

## 서비스 연결 지점과 남은 작업

2026-10-17 기준 main `725504d3c`에는 PR #1129·#1149가 통합돼 있다.
`Telescope.tsx`의 `TODO E1-5`가 항해 집중 연결 지점이며, 바다 방과 집중 세션의
실제 연결은 아직 없다. GROMO-2303은 디자인과 에셋 인계 및 확인용 화면을 제공하고,
GROMO-2309·2310에서 실제 진입 경로와 서버 어댑터를 연결한다.

GROMO-2310(2026-10-18)이 1·2·3·6을 `SeaVoyageHost`(라우트 `sea`·`seaArrival`)와
`services/seaRealtime.ts`로 연결했다. 남은 것은 4·5(GROMO-2311 결과창·보상·환영)다.

1. **2310 에서 연결** — 2299 세션 어댑터: `SeaVoyage`에 현재 세션·서버 시간·도착 판정을 전달한다.
   화면은 100% 진행률만으로 `canDisembark`를 추론하지 않는다. 서버 시간 보간,
   백그라운드 복귀 재조회, 세션 복원은 기존 세션 명령 계층에 연결해야 한다.
2. **2310 에서 연결** — 2300 방 어댑터: 방 전체(최대 10명)를 `participants`에 전달한다. 입퇴장,
   실시간 재연결/중복 이벤트, 한마디 5분 잠금, 이모트 TTL은 서버 계약대로 처리한다.
   화면에는 현재 `messageCooldownSeconds`와 아직 유효한 이모트만 전달한다.
   기존 한마디를 비우면 `onMessage('')`로 삭제를 요청한다. 삭제에도 같은 쿨다운을 적용한다.
3. **2310 에서 연결** — `onFinish(sessionId, intent)`: 기존 명령 계층에서 동일 의도의 멱등 키·버전·계정
   경계를 유지하며 종료한다. 성공한 정산 응답 또는 미확인 결과를 `result`로 전달한다.
   Promise 성공만으로 화면이 결과/보상을 추측하지 않는다.
   `intent`는 사용자 의도이며 서버의 최종 도착 상태를 대신하지 않는다. 오래된 스냅샷에서
   `stop`을 보냈더라도 이미 도착한 세션의 정산을 누락시키지 않도록 서버가 최종 상태로
   처리하거나 최신 상태와 함께 거절해야 한다. `voyage` 해제와 `result` 설정은 한 번에 전달한다.
   어댑터 요청에는 타임아웃·취소를 적용한다. 화면은 세션/결과 변경 시 이전 요청의 UI 잠금을
   해제하고, 이전 요청 완료가 새 요청의 잠금·오류·패널에 영향을 주지 않도록 구분한다.
4. **2311 에서 연결** — 카탈로그 기반 결과창(`GET /customization/catalog`, 없으면 id 만). 이전 메모: 2301 보상/2313 기본 단계표 데이터: `seaRewardCatalog`에 실제 itemId와 에셋을 매핑한다.
   현재 실사용 카탈로그는 비어 있고 오리는 `SeaPreview`에서만 주입된다.
   `rewards`는 서버가 지급한 모든 `grantedProductIds`를 순서대로 보존한다. 첫 아이템을 대표 이미지·이름으로, 나머지는 이름 목록으로 표시한다.
   `rewards`가 있으면 획득, 비어 있고 `rewardsUnknown=false`면 미획득 확인, `rewardsUnknown=true`면 확인 불가다.
   서버 `seaReward: null`은 지급 없음이 아니라 모름이므로 어댑터는 `rewardsUnknown=true`로 전달한다.
   복원 응답만으로 지급을 추측하지 않고 인벤토리 정본을 확인한다. 모르는 아이템은 id 만,
   미획득과 미확인은 각각 다른 문구를 표시한다. `minutesToNextTier`가 있으면 다음 단계까지 남은 분을 함께 보인다.
5. **2311 에서 연결** — `SeaVoyageHost.onExplore`(도착 기록·환영·인벤토리 재조회·방문/주민 라우트), 주민 소식 토스트는 `islandRealtime` events. 이전 메모: `onExplore(result)`: 결과 확인 처리·인벤토리 재조회·기존 방문자/주민 라우트 이동.
   첫 주민 환영/2302 주민 소식도 이 어댑터에서 기존 흐름과 연결한다.
6. **2310 에서 연결(망원경 쪽)** — 망원경 [항해하기] → `SeaVoyagePreparation` → 바다 항해 집중 시작
   → `SeaScreen`. 그만두기는 같은 finish 뒤 `Sailing`(1.9초)으로 멀어지고 표류 상태로 남는다.
   G1/G3 뗏목 행선지 「먼바다로」와 `SeaDeparture` 최초 출항 연출은 GROMO-2309 몫이다.
   한마디는 바다 세션에 과목이 없어 집중 중에도 말풍선에 뜬다(`SeaScene`).

`SeaVoyagePreparation`을 열 때 호스트는 배경 화면의 접근성을 숨기고 입력을 막아야 한다.
미리보기는 준비창이 열린 동안 장면과 도구 모음을 `no-hide-descendants`/`aria-hidden`으로 숨긴다.

계정 변경 시 호스트는 사용자 ID를 React key로 사용하여 화면을 재생성해야 한다.
`guest`가 참이거나 동적 boolean이면 `onSignIn`을 반드시 전달해 로그인 안내에서
실제 회원 전환 흐름으로 이동할 수 있게 한다. 회원 전용 화면은 둘 다 생략할 수 있다.
요청 취소/버전 충돌 처리는 명령 계층의 책임이며 UI의 중복 탭 방지로 대체하지 않는다.

## 에셋과 디자인

`seaAssets.ts`는 기존 뗏목 전후 레이어, 여섯 색의 `reading/atlas.png`와
`loaf/loaf.png`를 사용한다. 새 에셋은 OTA 포함 경로 `src/assets/ota/`에 둔다.
6색 모두 독서 정지 PNG(512×512), 독서 atlas(3072×512), loaf PNG(512×512)의
총 18개 파일이 실제 존재하는지 확인했다. 새 고양이 포즈는 제작하지 않았다.

- `sea/far-sea.jpg`: Figma S1 배경(imageHash `0b86e35e7765c15c59e8ee641e0fe7a654319252`) PNG 원본을 투명 픽셀이 없어 JPG(품질 85)로 바꿨다(GROMO-2379).
- `sea/seagulls.png`: S1 `1216:1300`.
- `sea/destination-island.png`: V2 `1216:1620`의 원본. 기존 목적지 미리보기 원본을 보관하며, 현재 항해 중·도착 후 화면에는 표시하지 않는다.
- `customization/head/duck.png`: `.docs/customization-assets-2026-10-16/assets-v3/head/duck.png` 원본.
  투명 여백은 변경하지 않고 최신 결과창의 표시 창/앵커로 배치한다.

집중 중인 참여자는 과목을 뗏목 위 말풍선에, 시간을 이름 바로 아래에 표시한다.
내 뗏목 아래 시간도 상단과 같은 세션 시간을 사용한다.

높이 660pt 미만의 가로 화면은 내 뗏목과 참여자를 두 줄로 배치하고 페이지 버튼을 상단으로 옮긴다.
상단 시간·도착 정보와 하단 버튼 사이의 높이에 맞춰 뗏목 크기를 조절하며 좌우 안전 영역을 반영한다.
세로 화면으로 돌아오면 기존 배치를 복원한다.

참여자 이름 배경은 글자 크기를 유지한 채 좌우 2pt·상하 0pt 여백과 55% 불투명도를 사용한다.

색·반경·간격은 기존 토큰, 버튼과 모달은 `Btn`·`Overlay`를 재사용한다.
모달 위치는 Figma의 고정 y=148 대신 공용 중앙 정렬/스크롤을 사용한다.
한마디·유저 카드·이모트 패널도 공용 모달을 사용하며 각 세부 시안의 완전한 픽셀 복제는 아니다.
